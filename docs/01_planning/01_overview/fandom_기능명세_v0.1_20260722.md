> [문1 · 기획 개요 & 핵심 정책]의 개념·정책을 전제로, **사용자가 무엇을 하는가**(화면·동작)만 다룬다. 점유/점령/어뷰징 같은 규칙은 여기서 재정의하지 않고 문1을 참조만 한다.
> 기능은 **3개 레이어**로 나눈다: A. 행동(성지) / B. 전황(땅) / C. 메타.
# 유저 시나리오 (핵심 흐름)
지수(뉴진스 팬)의 하루:
- 앱을 켜니 지도에서 **마포구가 빨강(아이브)으로 점령**된 게 보인다. 어제까진 중립이었는데 뺏겼다.
- 마포에 있는 **뉴진스 하니 생일카페(성지)**로 향한다.
- 아메리카노를 사고 영수증을 촬영 → AI 인증 → "인증 완료! 마포구 뉴진스 점유율 +0.4%".
- 지수의 한 방이 마포구를 **48% → 51%로 밀어올려 파랑으로 뒤집는다** → "당신이 마포구를 뉴진스 색으로 뒤집었습니다!" 푸시.
- 랭킹에서 지수의 이번 주 마포 기여도가 3위로 뜬다.
- 이틀 뒤, 아이브 팬들이 몰려와 마포를 되찾는다. 지수에게 "마포가 위태로워요" 방어 알림이 온다.
이 흐름에서 **장소**(카페)·**성지**(생일카페 이벤트)·**팬덤**(색)·**인증**(영수증)·**땅**(마포구)이 각자 역할을 갖는다. (개념 정의는 문1 3장)

# A. 행동 레이어 — 성지
## A1. 성지 지도 (홈)
- 한 화면에 **둘이 동시에** 뜬다: 성지 핀(행동 지점) + 구 단위 색칠(전황).
- 핀 상태: 진행중 이벤트 성지(D-day 뱃지), 상설 성지 구분.
- 필터: 선호 IP만 보기 토글.
- 정책 참조: 아카이브된 성지 핀은 내려가되 땅 색 기여는 감쇠 규칙(문1 4.2)에 따름.
## A2. 성지 상세
- 표시: 장소명, 이벤트명, 운영기간(D-day), **이 성지의** 팬덤별 점유율, 인증 CTA.
- 구 전체 점유는 여기가 아니라 B1에서 본다.
## A3. 영수증 인증 (핵심 입력)
플로우: 카메라 → OCR 판독 → 4겹 검증 → 결과.
- **귀속 팬덤**: 인증 시점에 유저가 고른 팬덤 1개 (그룹, 유닛, 개인/솔로/배우 중 선택).
- **단방향 상향 상속 (Upward Roll-up)**: 개인 멤버/유닛으로 인증 시, **최상위 단체 그룹의 전체 점수에도 100% 자동 상향 합산**되어 점령전에 기여함.
- **OCR 추출**: 사업자번호, 거래일시, 금액, 승인번호.
- **판정**: dedup 중복→반려 / 사업자번호 일치+인식률+GPS→자동승인 / 애매→수동검수 / 쿨다운 초과→반려. (규칙 상세는 문1 5장)
- **MVP 주의**: 자동대조는 사업자번호 등록된 성지만. 초기엔 수동검수 비중이 큼.
- **결과**: "인증 완료! ○○구 +0.X%" / 반려 사유. 원본 이미지는 검수 후 파기·마스킹.
# B. 전황 레이어 — 땅 (땅따먹기의 심장)
성지 인증이 구 단위로 집계돼 색으로 칠해지는 전장. **이 레이어가 "게임"을 만든다.**
## B1. 구별 점령 현황
- 각 구: 1위 팬덤 색 + 점유율 + **2위와의 격차**.
- 상태 뱃지: 점령(40%↑ 단독), 경합(격차 근소), 중립(미달).
## B2. 뺏고 뺏기는 실시간 알림
- 트리거: 구의 1위 팬덤이 바뀌는 순간("뒤집힘").
- 대상: 그 구에 기여한 유저 전원(양 팬덤). 마지막 한 방 유저는 "당신이 뒤집었습니다" 강조.
## B3. 방어 유도 (위태로움)
- 트리거: 내 팬덤이 점령 중인 구가 2위에게 격차 좁혀질 때.
- 알림: "마포가 위태로워요 — 5%p 차" → 재방문·인증 유도. 땅따먹기의 "지키는" 재미.
## B4. 개인 기여도
- 각 구에서 내 인증이 우리 팬덤 점유에 기여한 비중. "내가 이 땅을 만들었다"는 소속감.
## B5. 점령 타임라인
- 구별 색 변화 히스토리(누가 언제 점령·뺏김). 공유·바이럴 소재.
# C. 메타 레이어
## C1. 온보딩 + 로그인
- **선호 IP 선택**: [가수 / 배우 / 스포츠 / 애니] 2차원 장르 및 [그룹 / 유닛 / 개인] 3계층 IP 검색 지원 (상하위 연결 바로가기 제공).
- **신규 팬덤 신청**: 목록에 원하는 팬덤이 없는 경우 `[신규 팬덤 등록 신청]` 폼 제공 (어드민전용 심사 수신함 `ADM-IP-REQUEST-01`으로 이관 처리).
- **로그인**: OAuth 소셜 전용 — **한국 휴대폰 본인인증에 의존하지 않는다**(외국인 진입장벽 제거).
## C2. 랭킹 (Leaderboards)
- **앱 3대 랭킹 뷰**:
  1. `통합 그룹 랭킹`: 속한 모든 개인/유닛 멤버 점수를 합산한 그룹 전체 대항전 랭킹
  2. `개인 / 솔로 랭킹`: 개인 멤버 및 배우/스포츠 간의 순수 개별 랭킹
  3. `그룹 내 최애 랭킹`: 특정 그룹 안에서 멤버별 팬덤 기여도 % 랭킹
## C3. 국제화 (i18n)
- UI 다국어(한/영), 유저 locale·언어 필드. 상세 방침은 [문3 · 리스크 & 확장] 참조.
