## 프로젝트명: IP 팬덤 기반 "우리들의 성지 땅따먹기" (가칭)
### 1. 서비스 개요 및 비즈니스 목적
- Core Concept: 특정 엔터테인먼트 IP(K-POP 아티스트/그룹/유닛/개인, 배우, 스포츠, 애니 등)의 팬들이 오프라인 팝업스토어, 생일 카페 등을 방문해 영수증/사진으로 인증하고, 지도를 자신의 팬덤 컬러로 점령해 나가는 위치 기반(LBS) 게이미피케이션 커머스입니다.
- Value Proposition:
	- 고객(팬덤): 파편화된 팬덤 이벤트 정보를 지도 기반으로 통합 제공하고, [그룹 ↔ 유닛 ↔ 개인] 3계층 점유와 단방향 상향 점수 상속(Upward Roll-up)을 통해 개인 최애 응원 노력이 그룹 전체 대항전 랭킹 상승에도 100% 반영되는 소속감과 소속 시너지를 제공합니다.
	- 파트너(로컬/엔터사): 수동 운영(종이 도장 찍기, 명단 확인 등)의 한계를 AI 기술로 대체하여 인건비를 절감하고 지역 상권 트래픽을 유도합니다.
### 2. AI 기술 도입 핵심 모듈
- AI 영수증 OCR 비전 인증: 현장 스태프의 수동 확인을 대체합니다. 유저가 영수증을 촬영하면 AI가 `사업자 등록 번호`와 `결제 일시`를 추출해, 파트너 센터에 등록된 기준 데이터와 자동 대조 및 승인 처리합니다.
- 핫플레이스 자동 맵핑: 트위터 등 SNS의 비정형 텍스트 데이터를 AI가 분석하여, 수동으로 찾기 힘든 팬덤 '성지'의 좌표와 운영 일정을 실시간으로 지도에 업데이트합니다.
### 3. 프론트엔드 (App) 화면 아키텍처
클로드에게 UI 컴포넌트 생성을 요청할 때 기준이 되는 화면 구조입니다.
- [화면 1] 팬덤 성지 지도 (Home Map View)
	- Map Area: 폴리곤 형태의 팬덤별 점유 구역 컬러링 (그룹 합산 점수 기준), 개별 장소 핀 마커 (개인 최애 시그니처 컬러/엠블럼).
	- Floating Bar: `[내 주변 성지 리스트]` 스와이프 업 바텀 시트.
- [화면 2] 성지 상세 및 인증 모달 (Spot Detail Modal)
	- Header: 장소명, 운영 기간(D-Day 뱃지).
	- Progress Bar: 현재 장소의 팬덤별 실시간 점유율 현황 (예: A그룹 60% vs B그룹 40%).
	- CTA 버튼: `[영수증으로 인증하기]` (클릭 시 카메라 뷰어 오픈).
- [화면 3] AI 인증 결과 화면 (AI Verification Result)
	- Interaction: "AI가 사업자 번호를 판독 중입니다" 로딩 애니메이션.
	- Feedback: "인증 완료! 마포구 영토 점유율이 0.1% 상승했습니다" 결과 팝업.
- [화면 4] 랭킹 보드 (Leaderboard)
	- Tab: `[통합 그룹 대항전 랭킹]` / `[개인/솔로 아티스트 랭킹]` / `[그룹 내 최애 기여도 랭킹]`.

### 4. 파트너 백오피스 (Admin) 데이터 테이블 구조
다중 파트너사 입점 및 권한 관리(Permission Management)를 고려한 어드민 워크플로우입니다.
- [메뉴 1] 거점 등록 관리 (Spot Master)
	- 입력 필드: 매장명, 주소, 운영 일정.
	- 기준 데이터 세팅 (필수): AI 영수증 OCR 대조를 위한 해당 매장의 '사업자 등록 번호'.
- [메뉴 2] 인증 내역 관리 (Verification Data Table)
	- 주문 관리 워크플로우(OMS)를 차용하여 인증 상태값을 `[대기]` -> `[자동 승인]` / `[수동 검수]` -> `[최종 승인]` / `[반려]` 로 관리합니다.
	- 자동 승인 탭: AI 인식률 95% 이상으로 사업자 번호 일치가 확인된 건 리스트 (운영 리소스 제로).
	- 수동 검수 탭: 영수증 구겨짐 등으로 AI 인식률이 낮은 건 리스트. 관리자가 원본 이미지 대조 후 상태값을 수동으로 변경하며, 반려 시 사유를 선택해 유저에게 푸시 알림을 발송합니다.
### 5. 핵심 유저 스토리 (Core User Story)
- [온보딩] 유저는 프로필에 '선호 IP'를 설정하여, 자신과 관련된 오프라인 성지 정보만 필터링하여 볼 수 있다.
- [탐험] 유저는 지도상에 자신의 팬덤 컬러로 물든 지역과 성지 핀을 확인하여 소속감과 경쟁심을 느낄 수 있다.
- [인증] 유저는 성지에 방문해 결제한 영수증을 업로드하고, AI 승인을 통해 즉시 점령 포인트를 획득할 수 있다.
