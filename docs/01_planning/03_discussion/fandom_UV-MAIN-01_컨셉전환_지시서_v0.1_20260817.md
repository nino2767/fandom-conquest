# UV-MAIN-01 메인 화면 컨셉 전환 반영 지시서

> 대상 파일: `docs/02_design/02_userview_v0.4/fandom_userview_v0.4_20260817.html`
> 대상 화면: `UV-MAIN-01 · 메인 성지 지도`

## 배경 (방향 전환 이유)

현재는 "땅따먹기(영토 점령)"가 서비스 전면에 나서 있는데, 이 컨셉을 그대로 메인으로 밀면 유저에게 부담스럽게 느껴질 수 있음. 아래처럼 우선순위를 조정하고자 함.

- 1순위 프레임: "내가 좋아하는 아티스트가 다녀간 곳에, 나도 다녀왔다" — 개인적 팬심/순례 경험
- 2순위(부산물): 이 개인 인증들이 쌓이면 자연스럽게 영토 점령처럼 보인다 — 즉 정복 게임이 아니라 "최애의 발자취를 따라가는 순례"가 메인 정체성이고, 땅따먹기는 그 결과로 드러나는 서사

## 반영해야 할 변경사항

### 1. 지도 기본 레이어 변경
- 기존: 25개 구 GeoJSON 폴리곤을 DOMINATED/COMPETING/NEUTRAL/REVERSED 4색으로 항상 칠해서 보여줌 → 진영전 느낌이 강함
- 변경: 구 단위 진영 색칠은 기본 화면에서 제거하거나 아주 옅게 처리. 대신 "내가 선호하는 아티스트가 다녀간 성지" 핀들을 지도 위 기본 요소로 표시
- 핀은 상태 구분 필요: 내가 이미 인증(방문)한 곳 vs 아직 안 가본 곳 (예: 채워진 핀 / 빈 핀, 또는 채도 차이) → "내 성지순례 도장판" 같은 느낌으로

### 2. 진영 색 레이어는 토글로 분리
- "전황 보기" 같은 버튼/토글을 추가해서, 눌렀을 때만 기존 구별 점유율 색상 오버레이가 나타나는 구조로 변경
- 기본 진입 시에는 꺼진 상태(개인화 뷰가 기본값)로

### 3. 플로팅 CTA 카피 변경
- 기존: "📸 땅 뺏어오기"
- 변경 후보:
  - "📸 다녀왔어요 인증하기"
  - "📸 발자국 남기기" (추천 — 팬심 인증이면서 동시에 나중에 영토로 이어지는 서사를 자연스럽게 연결하는 은유)

### 4. 점유율/성과 표현 톤 변경
- 기존: 승패/전황 중계 톤 (예: "역전", "점령")
- 변경: 동행/누적 뉘앙스로. 예: "이 구, 뉴진스 팬 발자국 63%" 처럼 숫자는 유지하되 언어를 승패가 아닌 누적/동행 톤으로 교체

### 5. (영향 범위 큼, 별도 확정 필요) 하단 탭바 명칭
- "점령보드" → "발자취" 또는 "동행" 등으로 변경 검토
- 주의: IA 전체(다른 화면들 탭바 표기)에 영향을 주므로 신중하게 결정 필요. 이번 반영 범위에 포함할지 별도로 확정 후 진행할 것

## 체크리스트(`fw-check`) 업데이트 필요 항목

- "25개 구 GeoJSON 폴리곤 — DOMINATED/COMPETING/NEUTRAL/REVERSED 4상태 색상" → "전황 보기 토글 시에만 노출"로 조건부 명시
- "플로팅 CTA [📸 땅 뺏어오기]" → 변경된 문구로 교체
- 신규 항목 추가: "내 최애 성지 핀 표시 (방문/미방문 상태 구분)" 등 개인화 뷰 관련 항목 명시

## 열린 질문 (확정 필요)

- 발자국형 CTA 문구 최종안: "다녀왔어요 인증하기" vs "발자국 남기기" 중 확정
- 전황(진영 색) 토글 버튼을 화면 어디에 배치할지
- 탭바 명칭 변경 여부 및 반영 범위 (이번 v0.4에 포함할지, 별도 버전에서 처리할지)
