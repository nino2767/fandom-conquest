## 1. 팬(User) 정책 규격

### 1.1 자율적 팬덤 귀속 & 자기 신고
* **증명 절차 없음**: 특정 팬덤의 팬임을 증명하는 별도 인증(음원 스트리밍 내역, 공식 팬클럽 카드 등) 절차는 두지 않음.
* **자기 신고제**: 인증 순간 유저가 고른 팬덤에 1건의 점수(1점)가 귀속됨.
* **진입 허들 최소화**: 무거운 서류/인증 없이 누구나 즉시 팬덤 점령전에 참여 가능.

### 1.2 선호 팬덤 변경 & 과거 점수 불변 원칙 (소급 적용 불가)
* 유저는 마이페이지에서 **선호 팬덤 목록 및 메인 팬덤을 언제든지 변경**할 수 있음.
* **과거 점수 소급 불가**:
  * 유저가 선호 팬덤을 A그룹에서 B그룹으로 변경하더라도, **과거 A그룹 팬덤 이름으로 인증했던 내역과 기여 점수는 그대로 A그룹에 보존**됨.
  * 선호 팬덤 변경은 **변경 이후 새롭게 수행하는 영수증 인증 건에만 적용**.
  * **목적**: 팬덤 간 이적 시 기존 전황 지도의 점유율이 휘청이는 어뷰징 방지 및 게임 이력의 엄격한 일관성 유지.

## 2. 프로필 & 마이페이지 상세 기능 정의

### 2.1 마이페이지 메인 화면 컴포넌트
* **프로필 헤더**: 프로필 이미지, 닉네임, 메인 대표 팬덤 뱃지, 누적 인증 횟수.
* **나의 영토 기여도 카드**:
  * 내가 가장 많이 인증한 상위 구(區) 리스트 (예: 마포구 기여 1위, 성동구 기여 3위)
  * 내가 우리 팬덤 점유율에 기여한 총 포인트 및 지분율(%)
* **인증 히스토리 타임라인**:
  * 유저 본인이 업로드하여 승인 완료된 영수증 인증 로그 리스트
  * 항목: 성지명, 귀속 팬덤, 인증 일시, 점유율 상승 기여 (+0.X%)

## 3. 개인 랭킹 & 기여도 상세 기능 정의

### 3.1 랭킹 집계 및 탭 구조
* **[탭 1] 누적 개인 랭킹 (전체 / 구 단위)**
  * **기준**: 유저가 서비스 가입 후 성공한 총 영수증 인증 건수 (1건 = 1점)
  * **성격**: 영구 보존형 성취 랭킹 (성지 아카이빙 여부와 무관하게 누적)
* **[탭 2] 이주의 영토 기여도 랭킹 (구 단위)**
  * **기준**: 특정 구(區) 내에서 이번 주(월요일~일요일) 동안 가장 많은 인증을 올려 팬덤 승리에 기여한 상위 10인 유저 노출
  * **리워드 UX**: 구별 랭킹 1위 유저에게 **"마포구 수호신" / "성동구 개척자"** 전용 프로필 뱃지 부여
