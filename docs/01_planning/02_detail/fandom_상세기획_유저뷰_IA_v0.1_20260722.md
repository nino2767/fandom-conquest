# 팬덤 땅따먹기 상세기획 — 유저뷰 IA (User View Information Architecture)

> 본 문서는 '팬덤 땅따먹기' 사용자 웹/앱(User View)의 **전체 정보 구조도(IA Tree), 메뉴 계층, 화면 ID 및 화면별 주요 UI 요소·동작 명세**를 다룬다.

---

## 1. 유저뷰 정보 구조도 (IA Tree)

```
User View App
├── 1.0 Auth & Onboarding (인증 및 온보딩)
│   ├── 1.1 Splash Screen [UV-AUTH-00]
│   ├── 1.2 Social Login Modal [UV-AUTH-01]
│   ├── 1.3 Terms & LBS Agreement [UV-AUTH-02]
│   ├── 1.4 Profile & Nickname Setup [UV-AUTH-03]
│   └── 1.5 Fandom Preference Selection [UV-AUTH-04]
│
├── 2.0 Main Map & Spot (성지 지도 및 거점)
│   ├── 2.1 Home Map View [UV-MAIN-01]
│   ├── 2.2 Spot Detail Modal [UV-MAIN-02]
│   └── 2.3 Nearby Spots Sheet [UV-MAIN-03]
│
├── 3.0 Verification (영수증 인증 플로우)
│   ├── 3.1 Camera & Photo Picker [UV-VERIF-01]
│   ├── 3.2 AI OCR Scanning Progress [UV-VERIF-02]
│   ├── 3.3 Verification Success Result [UV-VERIF-03]
│   ├── 3.4 Manual Review Pending Sheet [UV-VERIF-04]
│   └── 3.5 Verification Rejection Modal [UV-VERIF-05]
│
├── 4.0 War Status & Leaderboard (전황 및 랭킹)
│   ├── 4.1 Territory War Dashboard [UV-WAR-01]
│   ├── 4.2 Leaderboard Main [UV-RANK-01]
│   └── 4.3 My Territory Contribution Detail [UV-RANK-02]
│
└── 5.0 My Page & Settings (마이페이지 및 설정)
    ├── 5.1 My Profile Main [UV-MY-01]
    ├── 5.2 Edit Fandom Preferences [UV-MY-02]
    ├── 5.3 Verification Log History [UV-MY-03]
    └── 5.4 App Settings & i18n [UV-MY-04]
```

## 2. 화면별 세부 기능 명세 (Screen-by-Screen Specification)

### 2.1 Auth & Onboarding (인증 및 온보딩)

| 화면 ID | 화면명 | 진입 경로 | 주요 UI 구성요소 | 주요 동작 및 인터랙션 |
| :--- | :--- | :--- | :--- | :--- |
| **`UV-AUTH-00`** | 스플래시 | 앱 시작 | 서비스 로고, 애니메이션 | 토큰 유효성 검사 ➔ 자동 로그인 or 메인 지도(게스트) 진입 |
| **`UV-AUTH-01`** | 소셜 로그인 모달 | 게스트 CTA 클릭 시 | 구글/카카오/애플 로그인 버튼, 게스트 구경하기 닫기 | OAuth 프로바이더 이동 ➔ 인증 완료 후 `UV-AUTH-02` 이동 |
| **`UV-AUTH-02`** | 약관 동의 | 최초 가입 시 | 서비스 약관(필수), 개인정보(필수), **LBS 위치약관(필수)**, 마케팅(선택) | `[전체 동의]` 체크박스 ➔ `[다음]` 활성화 후 `UV-AUTH-03` 이동 |
| **`UV-AUTH-03`** | 프로필 설정 | 약관 동의 후 | 닉네임 입력 폼, 중복확인 버튼, 프로필 이미지 픽커 | 실시간 닉네임 유효성(2~12자/비속어) 검증 ➔ `[다음]` 활성화 |
| **`UV-AUTH-04`** | 선호 팬덤 선택 | 프로필 설정 후 | 팬덤 검색 폼, IP 그래픽 카드리스트, 메인 팬덤 대표 설정 라디오 | 최소 1개 이상 다중 선택 필수 ➔ 온보딩 완료 후 메인 지도 진입 |

### 2.2 Main Map & Spot (성지 지도 및 거점)

| 화면 ID | 화면명 | 진입 경로 | 주요 UI 구성요소 | 주요 동작 및 인터랙션 |
| :--- | :--- | :--- | :--- | :--- |
| **`UV-MAIN-01`** | 메인 지도 (홈) | 메인 탭 | LBS 지도, 구별 팬덤 점령 폴리곤, 성지 마커(D-day 뱃지), 선호 IP 필터 토글, 내위치 버튼 | • 지도 이동/확대/축소<br>• 구 클릭 시 전황 요약 팝업<br>• 마커 클릭 시 `UV-MAIN-02` 오픈 |
| **`UV-MAIN-02`** | 성지 상세 모달 | 마커 클릭 시 | 장소명, 이벤트명, 운영기간(D-day), 주소, 팬덤별 점유율 Progress Bar, `[영수증 인증]` CTA | • 점유율 시각화 프로그레스바<br>• `[영수증 인증하기]` 클릭 ➔ `UV-VERIF-01` 이동 (게스트면 `UV-AUTH-01`) |
| **`UV-MAIN-03`** | 주변 성지 바텀시트 | 메인 지도 바텀시트 | 스와이프 핸들, 뷰포트 내 성지 카드 리스트 (거리순/마감임박순) | 바텀시트 스와이프 업 ➔ 전체 카드 리스트 확장 노출 |

### 2.3 Verification (영수증 인증 플로우)

| 화면 ID | 화면명 | 진입 경로 | 주요 UI 구성요소 | 주요 동작 및 인터랙션 |
| :--- | :--- | :--- | :--- | :--- |
| **`UV-VERIF-01`** | 영수증 촬영/선택 | 성지 상세 CTA 클릭 | 카메라 뷰파인더, 영수증 정렬 가이드 프레임, 갤러리 불러오기 버튼 | • 영수증 촬영/선택 ➔ 이미지 크롭 & 판독 준비 |
| **`UV-VERIF-02`** | AI OCR 스캐닝 | 촬영 직후 | 스캐닝 레이저 애니메이션, "AI가 사업자번호와 승인번호를 읽고 있습니다" 메시지 | 4개 필드 추출 ➔ 4겹 방어 판정 (2초 내 완료) |
| **`UV-VERIF-03`** | 인증 성공 피드백 | 스캐닝 성공 시 | 🎉 승인 폭죽 애니메이션, 기여 점유율(`+0.4%`), 뒤집힘/수호신 특수 뱃지 피드백 | `[지도에서 내 땅 확인하기]` ➔ 메인 지도 뷰포트 이동 |
| **`UV-VERIF-04`** | 수동 검수 대기 | 판정 플래그 시 | ⏳ 검수 대기 캐릭터 보드, "10분 내로 관리자 확인 후 반영됩니다" 카피 | `[확인]` 클릭 ➔ 성지 상세 모달로 복귀 |
| **`UV-VERIF-05`** | 인증 반려 모달 | 하드 반려 시 | ⚠️ 반려 아이콘, 반려 사유 텍스트, `[다시 촬영하기]` CTA | 사유 안내 (중복 영수증, 쿨다운 초과 등) ➔ 재촬영 유도 |

### 2.4 War Status & Leaderboard (전황 및 랭킹)

| 화면 ID | 화면명 | 진입 경로 | 주요 UI 구성요소 | 주요 동작 및 인터랙션 |
| :--- | :--- | :--- | :--- | :--- |
| **`UV-WAR-01`** | 영토 전황 보드 | 하단 탭 [전황] | 서울시 전체 지도 카토그램, 구별 점령 1위 팬덤 리스트, 2위 격차(%p), 치열한 경합구 뱃지 | • 구 선택 시 실시간 뒤집힘 히스토리 타임라인<br>• `[이 구에 기여하러 가기]` 성지 안내 |
| **`UV-RANK-01`** | 랭킹 보드 메인 | 하단 탭 [랭킹] | [누적 개인 랭킹] / [팬덤 영토 랭킹] 탭, 구 단위 필터, Top 3 포디움 UI, 1~100위 랭킹 리스트 | • 탭 전환 및 구별 랭킹 필터링<br>• 내 위치 랭킹 하단 고정 바 노출 |
| **`UV-RANK-02`** | 개인 기여도 상세 | 랭킹 내 내 계정 클릭 | 내 수호신 뱃지, 구별 내 인증 점수, 우리 팬덤 지분율(%) | 각 구별 내 기여 지분율 상세 카드 노출 |

### 2.5 My Page & Settings (마이페이지 및 설정)

| 화면 ID | 화면명 | 진입 경로 | 주요 UI 구성요소 | 주요 동작 및 인터랙션 |
| :--- | :--- | :--- | :--- | :--- |
| **`UV-MY-01`** | 마이 프로필 메인 | 하단 탭 [마이] | 프로필 헤더, 대표 팬덤 뱃지, 누적 인증 횟수, 획득 수호신 뱃지 카드, 내 인증 내역, 설정 아이콘 | 프로필 관리 및 서브 메뉴 진입 |
| **`UV-MY-02`** | 선호 팬덤 관리 | 마이페이지 프로필 수정 | 선호 팬덤 카드리스트, 대표 메인 팬덤 라디오 토글 | 팬덤 추가/삭제 및 메인 대표 팬덤 변경 (과거 점수 소급불가 안내) |
| **`UV-MY-03`** | 인증 내역 히스토리 | 마이페이지 내 메뉴 | 승인/대기/반려 상태 탭, 인증 영수증 내역 리스트 (성지명, 일시, 귀속팬덤, 점유기여) | 각 인증 건 클릭 시 성지 상세 연결 |
| **`UV-MY-04`** | 서비스 설정 | 마이페이지 톱니바퀴 | 푸시 알림 토글 (뒤집힘/위태로움/이벤트), 언어 설정(i18n: 한국어/English), 약관 보기, 탈퇴하기 | 푸시 수신여부 설정 및 회원 탈퇴 프로세스 |
