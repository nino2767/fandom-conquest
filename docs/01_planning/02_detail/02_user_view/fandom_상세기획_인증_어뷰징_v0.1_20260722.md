## 1. 영수증 OCR 인증 파이프라인

유저가 성지에서 영수증을 촬영하여 제출 시 실행되는 단계별 인증 프로세스입니다.

```mermaid
flowchart TD
    Cam["카메라 영수증 촬영"] --> OCR["AI OCR 비전 판독<br/>(4개 필드 추출)"]
    OCR --> Dedup{"1차: dedup_key 중복?"}
    Dedup -- "예" --> Reject1["[즉시 반려]<br/>이미 사용된 영수증"]
    Dedup -- "아니오" --> Match{"2차: 사업자번호 일치 &<br/>GPS 200m 이내?"}
    Match -- "미일치/외곽" --> Queue["[수동 검수 큐]<br/>관리자 원본 검토"]
    Match -- "일치" --> Cool{"3차: 1일 쿨다운 초과?"}
    Cool -- "초과" --> Reject2["[즉시 반려]<br/>오늘 이미 인증함"]
    Cool -- "통과" --> AutoApprove["[자동 승인 확정]<br/>구 점유율 +0.X% 즉시 반영"]
```

### 1.1 AI OCR 4개 추출 필드
1. **사업자등록번호 (Business Registration No)**: 10자리 숫자 (성지 장소 일치 대조용)
2. **거래일시 (Transaction Datetime)**: YYYY-MM-DD HH:mm:ss (최신성 및 운영기간 검증용)
3. **결제금액 (Total Amount)**: KRW 결제 금액
4. **승인번호 (Approval No)**: 카드/현금영수증 승인번호 8~12자리 (고유 중복 차단키)

---

### 1.2 영수증 최신성(Freshness) 유효기간 정책 & 백엔드 자동 검증 플로우

실시간 현장 점령전의 게임성을 보장하고 오래된 영수증 모아 올리기/도용 어뷰징을 차단하기 위해 **영수증 결제일시의 최신성 검증**을 100% 실행합니다.

* **이벤트형 성지 (`EVENT`)**: 결제일시가 **성지 공식 운영기간 이내**이어야 하며, **결제 시각 기준 최근 3일 이내 (72시간 이내)** 제출건만 인정.
* **상설형 성지 (`PERMANENT`)**: 결제 시각 기준 **최근 7일 이내 (168시간 이내)** 영수증만 인정.

```mermaid
flowchart TD
    Scan["영수증 OCR 스캐닝"] --> ExtractDate["결제일시(transaction_at) 파싱"]
    ExtractDate --> CheckNull{"결제일시 파싱 성공?"}
    
    CheckNull -- "실패" --> FlagReview["4차 수동검수 큐 (ADM-VERIF-04) 이관"]
    CheckNull -- "성공" --> CheckSpotType{"성지 유형 체크"}
    
    CheckSpotType -- "이벤트형 (EVENT)" --> EventCheck{"1) 성지 운영기간 이내?<br/>2) 결제 후 3일 이내?"}
    CheckSpotType -- "상설형 (PERMANENT)" --> PermCheck{"결제 후 7일 이내?"}
    
    EventCheck -- "Yes" --> Pass["최신성 검증 통과 (인증 진행)"]
    EventCheck -- "No" --> Reject["❌ 반려 (UV-VERIF-05): 운영기간 미부합 또는 3일 초과"]
    
    PermCheck -- "Yes" --> Pass
    PermCheck -- "No" --> Reject2["❌ 반려 (UV-VERIF-05): 7일 경과 영수증"]
```

## 2. 4겹 어뷰징 방어 상세 규격

### 2.1 1차 방어: 승인번호 유니크 키 (Dedup Key)
* **`dedup_key` 규칙**: `[사업자등록번호] + [승인번호]` (승인번호 미인식 시 `[사업자번호] + [거래일시] + [결제금액]` 조합키)
* **목적**: 동일 영수증 재촬영, 이미지 캡처/도용을 DB Unique 인덱스로 100% 근본 차단.

### 2.2 2차 방어: GPS 반경 대조 (Location Verification)
* **반경 규격**: 성지 지점 기준 **반경 200m 이내** 유저 위치 확인.
* **유연한 처리**: 반경 밖에서 업로드 시 즉시 하드 반려하지 않고 **`플래그(Flag)`** 처리 후 어드민 **수동 검수 큐**로 전달 (통신 장애/매장 내부 GPS 오차 유저 포용).

### 2.3 3차 방어: 쿨다운 & 건수 기반 점수
* **쿨다운 규칙**: 유저 1인당 동일 성지에서 **1일 1회 인증 제한** (자정 KST 기준 리셋).
* **1건 = 1점 고정**: 결제 금액과 무관하게 1건당 1점 고정 부여 ➔ 소액 결제 반복 펌핑 행위 무효화.

### 2.4 4차 방어: 이상탐지 수동 검수 큐 (Anomaly Detection)
* 단시간 내 특정 매장 인증 건수 이상 급증, 동일 IP 다계정 접근 탐지 시 자동 승인 즉시 보류 및 어드민 수동 검수 큐 이관.

## 3. 인증 결과 처리 및 에러 UX 메시지 명세

| :--- | :--- | :--- |
| **자동 승인** | 점유율 즉시 반영 (`+0.4%`) | 🎉 **"인증 완료! [마포구] [뉴진스] 점유율이 +0.4% 상승했습니다!"** |

## 4. 개인정보 보호 & 마스킹 처리

* **영수증 원본 이미지 파기**: OCR 필요 필드(사업자번호, 일시, 금액, 승인번호) 파싱이 완료되면 영수증 원본 이미지에서 마스킹(카드번호 일부 제거) 처리 후 **최대 7일 내 원본 파기**.
* **데이터 저장 최소화**: 개인 신용카드 정보는 절대 저장하지 않음.

## 5. 카메라 촬영 가이드 UX & 권한 예외 처리

### 5.1 촬영 가이드 UX (Camera Overlay)
* **뷰파인더 오버레이**: 영수증 직사각형 가이드 프레임 제공 ("영수증을 사각형 프레임 안에 평평하게 정렬해 주세요").
* **환경 안내 메시지**: 
  * "어두운 곳에서는 밝은 조명 아래에서 찍어주세요."
  * "영수증의 승인번호와 사업자번호가 잘 보이도록 펼쳐주세요."

### 5.2 카메라 및 위치 권한 거부 시 예외 UX
* **카메라 권한 거부 시**: `[권한 필요]` 모달 팝업 ➔ *"영수증 스캔을 위해 카메라 접근 권한이 필요합니다. [디바이스 설정으로 이동]"* 안내.
* **위치(GPS) 권한 거부 시**: 위치 정보 미제공 시 인증 제출 불가능 ➔ *"성지 반경 확인을 위해 위치 서비스 권한을 허용해 주세요"* 안내.
