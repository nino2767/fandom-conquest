#### A. 프로필 헤더 (Profile Header)
* **프로필 이미지**: 소셜 계정 기본 프로필 이미지 또는 서비스 캐릭터 프로필 중 선택.
* **닉네임 정책 & 유효성 검수**: 최소 2자 ~ 최대 12자 (중복 실시간 체크 `GET /api/v1/users/check-nickname`, 금지어/사칭어 필터링).
* **활동 지표**: 가입 일수 (D+XX일), 누적 영수증 인증 횟수, 총 획득 뱃지 수.

#### B. 수호신 뱃지 수집함 (Guardian Badge Gallery)
* **획득 뱃지 (컬러)** vs **미획득 뱃지 (흑백 Grayscale)** 구분 렌더링 (클릭 시 획득 조건 팝업).

| 뱃지 ID | 뱃지 이름 | 획득 조건 명세 | 시각적 특징 |
| :--- | :--- | :--- | :--- |
| `BADGE-01` | **[구(區) 이름] 수호신** | 특정 구(區)에서 주간 내 인증 1위 달성 시 | 금빛 깃발 및 고유 구 이름 각인 |
| `BADGE-02` | **영토 개척자** | 점령되지 않은 중립(무주공산) 구에 첫 인증 성공 시 | 은빛 깃발 아이콘 |
| `BADGE-03` | **역전의 주역** | 내 인증으로 구 1위 팬덤 색상이 뒤집히는 순간 기여 시 | 붉은 불꽃 역전 뱃지 |
| `BADGE-04` | **성지 순례자** | 서로 다른 성지 5곳 이상 인증 성공 시 | 지도 핀 뱃지 |
| `BADGE-05` | **열혈 칭호** | 7일 연속 영수증 인증 성공 시 | 7일 리본 뱃지 |

### 2.2 [화면 2] 선호 팬덤 관리 & 신규 팬덤 신청 (`UV-MY-02`)

- **선호 팬덤 3계층 검색**: [가수 / 배우 / 스포츠 / 애니] 2차원 장르 및 [그룹 ↔ 유닛 ↔ 개인] 3계층 트리 검색 지원 (상하위 연결 칩 바로가기 포함).
- **신규 팬덤 등록 신청 모달**:
  - 검색 결과에 원하는 팬덤이 없는 경우 `[+ 원하시는 팬덤이 없으신가요? 신청하기]` CTA 노출.
  - 신청 데이터 폼: `신청 팬덤명`, `아티스트명`, `장르 분류`, `신청 사유 / 대표곡` 입력.
  - 제출 시 어드민 전용 수신함 (`ADM-IP-REQUEST-01`)으로 이관되어, 어드민 승인 완료 시 **"신청하신 팬덤이 정식 등록되었습니다!"** 푸시 알림 수신.


```
+-------------------------------------------------------------+
|  [ ‹ 뒤로가기 ]              선호 팬덤 관리 (이적)          |
+-------------------------------------------------------------+
|  💡 관심 팬덤을 다중 선택하고, 기본 인증 귀속 팬덤을 지정하세요.|
|  ⚠️ 대표 메인 팬덤 변경 시 7일간 재변경이 제한됩니다.        |
+-------------------------------------------------------------+
|  [ 🔍 팬덤/아티스트 검색 (예: 뉴진스, 아이브...)          ] |
+-------------------------------------------------------------+
|  💙 [ 메인 대표 팬덤 지정 (라디오 선택) ]                    |
|  (●) 뉴진스 (NewJeans)     - [메인 지정됨]                   |
|  ( ) 아이브 (IVE)                                           |
|  ( ) 세븐틴 (SEVENTEEN)                                     |

|  [✓] 뉴진스    [✓] 아이브    [✓] 세븐틴    [ ] 방탄소년단     |
|  [ ] 블랙핑크  [ ] 에스파    [ ] 스트레이키즈                |
+-------------------------------------------------------------+
|  💾 [ 변경 사항 저장하기 ]                                  |  <-- Save CTA
|  * 메인 팬덤 변경 시 ⚠️ [과거 점수 소급 불가 & 7일 쿨다운 동의] |
|    팝업 모달 노출 후 최종 적용                              |

```

* **메인 대표 팬덤 이적 7일 쿨다운**: 변경 저장 시 7일간 재변경 불가 타이머 세팅 (`next_fandom_change_available_at`).
* **과거 점수 소급 불가 팝업**: ⚠️ *"기존 인증 과거 점수와 땅 점유 이력은 기존 팬덤에 보존되며, 변경 이후 인증부터 적용됩니다."*
