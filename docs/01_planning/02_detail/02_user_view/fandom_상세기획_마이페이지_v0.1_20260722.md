## 1. 개요 & 화면 구조

```
My Page & Settings
├── 1.0 My Profile Main [UV-MY-01]
│   ├── 1.1 Profile Header (프로필 헤더 & 닉네임 수정)
│   ├── 1.2 Guardian Badge Gallery (수호신 뱃지 수집함)
│   └── 1.3 Territory Contribution Cards (영토 기여 지분율)
├── 2.0 Edit Fandom Preferences [UV-MY-02] (선호 팬덤 관리)
├── 3.0 Verification Log History [UV-MY-03] (내 인증 내역 타임라인)
├── 4.0 Notification Center [UV-NOTIF-01] (알림 센터)
└── 5.0 App Settings & Account [UV-MY-05] (설정 및 회원 탈퇴)
```

## 2. 세부 화면별 상세 명세

### 2.1 [화면 1] 마이 프로필 메인 (`UV-MY-01`)

#### A. 프로필 헤더 (Profile Header)
* **프로필 이미지**:
  * 소셜 계정 기본 프로필 이미지 또는 서비스 전용 팬덤 캐릭터 프로필 4종 중 선택.
  * `[프로필 수정]` 클릭 ➔ 이미지 변경 및 닉네임 수정 폼 오버레이 오픈.
* **닉네임 정책 & 유효성 검수**:
  * **길이**: 최소 2자 ~ 최대 12자 (한글, 영문, 숫자 허용, 공백 불가).
  * **중복 검증**: 실시간 중복 체크 API 호출 (`GET /api/v1/users/check-nickname`).
  * **금지어 필터링**: 비속어, 타 팬덤 비하어, 엔터사/아티스트 공식 사칭명 입력 시 ⚠️ *"사용할 수 없는 닉네임입니다"* 에러 텍스트 표시.
* **대표 메인 팬덤 뱃지**: 유저가 지칭한 대표 팬덤의 시그니처 뱃지 및 고유 컬러 링 표시 (예: `NewJeans 💙`).
* **활동 지표**: 가입 일수 (D+XX일), 누적 영수증 인증 횟수, 총 획득 뱃지 수.

#### B. 수호신 뱃지 수집함 (Guardian Badge Gallery)
* **기능**: 유저가 서비스 활동을 통해 획득한 게이밍 뱃지 컬렉션 시각화.
* **뱃지 상태**:
  * **획득한 뱃지**: 선명한 대표 컬러 및 반짝임 인터랙션 효과.
  * **미획득 뱃지**: 흑백(Grayscale) 처리 및 뱃지 클릭 시 획득 조건 팝업 툴팁 노출.
* **주요 뱃지 라인업 명세**:

| 뱃지 ID | 뱃지 이름 | 획득 조건 명세 | 시각적 특징 |
| :--- | :--- | :--- | :--- |
| `BADGE-01` | **[구(區) 이름] 수호신** | 특정 구(區)에서 주간 내 인증 1위 달성 시 | 금빛 깃발 및 고유 구 이름 각인 |
| `BADGE-02` | **영토 개척자** | 점령되지 않은 중립(무주공산) 구에 첫 인증 성공 시 | 은빛 깃발 아이콘 |
| `BADGE-03` | **역전의 주역** | 내 인증으로 구 1위 팬덤 색상이 뒤집히는 순간 기여 시 | 붉은 불꽃 역전 뱃지 |
| `BADGE-04` | **성지 순례자** | 서로 다른 성지 5곳 이상 인증 성공 시 | 지도 핀 뱃지 |
| `BADGE-05` | **열혈 칭호** | 7일 연속 영수증 인증 성공 시 | 7일 리본 뱃지 |

#### C. 나의 영토 기여 요약 카드 (Territory Contribution)
* **내 기여 구(區) 리스트**: 유저가 영수증 인증을 올린 주요 구 목록 카드 (예: 1위 마포구 / 2위 성동구).
* **기여 지분율 (%)**: 해당 구(區) 내에서 우리 팬덤 전체 누적 점수 중 내 인증이 차지하는 기여 비중 시각화 (예: *"마포구 뉴진스 점유 점수 120점 중 내 기여 15점 (지분율 12.5%)"*).

### 2.2 [화면 2] 선호 IP (팬덤) 관리 (`UV-MY-02`)

* **응원 팬덤 선택 (다중 체크)**: 서비스에 등록된 전체 팬덤 카드리스트 중 내가 관심 있는 IP 다중 선택.
* **대표 메인 팬덤 지정 (라디오)**: 지도 접속 및 영수증 인증 시 기본 귀속 팬덤으로 자동 채워질 대표 1개 메인 팬덤 지정.
* **과거 점수 소급 불가 안내 모달**:
  * 선호 팬덤 변경 저장 클릭 시 ⚠️ **"선호 팬덤 변경 동의"** 팝업 노출.
  * 카피: *"선호 팬덤을 변경하더라도 이미 인증을 완료한 과거 점수와 땅 점유 이력은 기존 팬덤에 보존되며, 변경 이후 인증부터 새 팬덤에 적용됩니다."*
  * `[동의하고 변경 완료]` 클릭 시 변경 적용.

### 2.3 [화면 3] 내 인증 내역 타임라인 (`UV-MY-03`)

* **4개 상태 필터 탭**:
  * `[전체]` / `[승인 완료 (APPROVED)]` / `[검수 대기 (PENDING)]` / `[반려됨 (REJECTED)]`
* **인증 로그 카드 UI 요소**:
  * **상단**: 인증 상태 뱃지 (승인완료/검수대기/반려), 귀속 팬덤 태그
  * **본문**: 성지 장소 상호명, 이벤트명, 거래일시 (`YYYY-MM-DD HH:mm`), 점유율 상승 기여도 (`+0.4%`)
  * **썸네일**: 파싱된 영수증 마스킹 썸네일 이미지
* **반려 상세 사유 & 재인증 모달**:
  * `[반려됨]` 뱃지 카드 클릭 시 상세 팝업 오픈.
  * **사유 표기**: 사유 예시 (*"동일 영수증 중복 제출"*, *"오늘 해당 성지 인증 쿨다운 초과"*, *"사업자등록번호 미일치"*)
  * **CTA 버튼**: **`[다시 영수증 촬영하기]`** ➔ 해당 성지 인증 카메라 화면으로 즉시 이동.

### 2.4 [화면 4 & 5] 알림 센터 & 설정 (`UV-NOTIF-01`, `UV-MY-05`)

#### A. 알림 센터 (`UV-NOTIF-01`)
* **목적**: 디바이스 푸시 알림 수신 이력을 모아보는 내역 센터.
* **알림 유형**:
  * 🚩 **뒤집힘 알림**: *"아이브 팬덤이 마포구를 점령했습니다!"* (클릭 시 마포구 지도 이동)
  * ⚠️ **방어 유도 알림**: *"마포구가 위태로워요! 2위와 3%p 격차"* (클릭 시 마포구 성지 리스트 이동)
  * ✅ **인증 결과 알림**: *"성수 어반소스 영수증 인증이 최종 승인되었습니다"*

#### B. 앱 설정 & 계정 탈퇴 (`UV-MY-05`)
* **푸시 알림 수신 토글**:
  * `뒤집힘 알림 수신` (ON/OFF)
  * `방어 유도 위태로움 알림 수신` (ON/OFF)
  * `이벤트 & 마케팅 알림 수신` (ON/OFF)
* **i18n 다국어 언어 선택**: `한국어 (ko-KR)` / `English (en-US)` 지원.
* **회원 탈퇴 (Account Deletion)**:
  * 탈퇴 클릭 시 🚨 **"회원 탈퇴 확인"** 모달 오픈.
  * 카피: *"탈퇴 시 유저의 개인정보(소셜 ID, 이메일, 닉네임)는 즉시 파기되며 복구할 수 없습니다. 단, 기존에 인증하여 팬덤과 땅 점유율에 기여한 점수 데이터는 팬덤 공동 소유로 익명 처리되어 유지됩니다."*
  * `[약관에 동의하며 탈퇴합니다]` 체크박스 선택 후 탈퇴 완료.
