## 1. 팬덤 IP 데이터 모델 & 시각화 토큰 (Fandom IP Tokens)

### 1.1 고유 색상 및 브랜드 토큰
* **대표 고유 컬러 (Primary Hex Color)**: 지도 폴리곤 채색 및 마커에 적용 (예: 뉴진스 `#1E88E5`, 아이브 `#E53935`, 세븐틴 `#9C27B0`).
* **대비 보장 규칙**: 가시성을 위해 대비(Contrast Ratio) 4.5:1 미만 컬러 충돌 시 보조 서브 컬러(Secondary Color)로 자동 조율.
* **팬덤 이명/별칭 매핑**: 검색/인증 시 `NewJeans`, `뉴진스`, `버니즈` 등 다국어 키워드를 **단일 팬덤 ID**로 통합 파싱.

### 1.2 무소속 유저 (Unaffiliated User) 처리
* 온보딩 시 `[나중에 선택하기 (무소속)]` 선택 유저가 올린 인증 건은 특정 팬덤 점수로 집계되지 않으며, **'무소속 지분'**으로 별도 아카이브 집계.

### 1.3 3계층 IP & 단방향 상향 점수 상속 렌더링 룰 (Dual Roll-up UI)
* **지도 성지 핀 마커**: 유저가 메인 최애로 선택/인증한 **[개인 멤버/유닛 IP]의 시그니처 대표 컬러 및 엠블럼**을 지도 핀으로 우선 표기 (개인 자부심 제공).
* **25구 영토 전체 채색**: 25구 영토 40% 점령 컬러링 계산 시, 개인/유닛 점수가 상향 상속합산된 **[최상위 루트 그룹 합산 점수]**를 기준으로 점령 팬덤 색상을 채색하여 대규모 영토전 스케일 유지.

## 3. 14일 롤링 감쇠(Decay) 및 점수 합산 수학 공식

### 3.1 14일 롤링 감쇠 알고리즘 (Decay Algorithm)
상설형 성지 점수의 무한 누적으로 인한 세대교체 블로킹을 방지하기 위해 **인증 시점부터 14일(336시간) 동안 선형 감쇠**가 적용됩니다.

* **감쇠 가중치 공식**:
  $$Score(t) = S_{base} \times \max\left(0, \frac{336 - t}{336}\right)$$
  *(여기서 $t$는 인증 시점으로부터 경과된 시간(Hour), $S_{base}$는 인증 건당 베이스 점수)*
* ✨(v0.2) **베이스 점수 $S_{base}$ 가변화**: [fandom_상세기획_인증_어뷰징_v0.2_20260817.md](file:///Users/jmk/develop/fandom-conquest/docs/01_planning/02_detail/02_user_view/fandom_상세기획_인증_어뷰징_v0.2_20260817.md) §1의 인증 조합에 따라 고정 `1.0`이 아닌 **`1.0`(기본) / `1.5`(리뷰) / `2.0`(영수증) / `2.5`(복합)** 중 하나가 각 인증 건의 $S_{base}$로 대입되며, 이후 동일한 14일 선형 감쇠가 적용됨.
* **집계 방식**: 매일 자정 KST 기준 14일이 지난 옛날 인증 점수는 자동 차감 소멸.

### 3.2 이벤트형 vs 상설형 성지 점수 합산 방식
* **이벤트형 성지 (`EVENT`)**: 운영 기간 동안 감쇠 없이 **100% 점수 유지**, 운영 종료 자정 후 **즉시 0점 소멸**.
* **상설형 성지 (`PERMANENT`)**: 위의 **14일 롤링 감쇠 공식** 적용.

## 5. 실시간 뒤집힘/방어 푸시 알림 디바운스(Debounce) 정책

* **뒤집힘 푸시**: 1위 역전 즉시 발송. 단, 동일 구(區)에서 10분 내 재역전 반복 발생 시 푸시 도배 방지를 위해 **10분 푸시 디바운스 쿨다운** 적용.
* **위태로움 방어 푸시**: 격차가 5%p 이내로 좁혀졌을 때 해당 구 기여 유저에게 발송 (유저당 24시간 내 동일 구 1회 발송 제한).
