# 팬덤 땅따먹기 상세기획 — 장소 & 성지 (Place & Spot)

> 본 문서는 [fandom_핵심정책_v0.1_20260722.md](file:///Users/jmk/develop/fandom-conquest/docs/01_planning/01_overview/fandom_핵심정책_v0.1_20260722.md)의 장소(Place)·성지(Spot) 도메인 정책과 지도(Map)·성지 상세(Spot Detail) 화면의 **상세 기능 정의**를 다룬다.

---

## 1. 장소(Place) 식별 & 상태전이 규격

### 1.1 유일키 및 식별 규칙
* **유일키**: **사업자등록번호 (10자리)**
* **원칙**: 상호명이나 지번/도로명 주소 표기가 흔들려도 사업자번호가 동일하면 **동일 장소**로 인식.
* **복합몰/푸드코트 처리**: 동일 건물 주소라도 사업자번호가 다르면 지도의 별개 장소(근접 핀)로 각각 등록.

### 1.2 장소 상태전이 (Status Lifecycle)
* **`active` (운영 중)**: 정상 영업 중인 물리 사업장. 성지 생성 가능.
* **`closed` (폐업/양도)**:
  * 장소가 폐업하더라도 과거 영수증 인증 이력과 팬덤 땅 점유 기록 보호를 위해 DB 레코드 삭제 금지 (`status = closed`).
  * 사업자번호 변경 시(매장 양도/신규 개업): 기존 장소는 `closed` 처리하고, 새 사업자번호로 신규 장소 생성.

## 2. 성지(Spot) 판정 & 유형별 관리 규격

### 2.1 성지의 2가지 유형
* **이벤트형 성지 (한시적)**:
  * 생일카페, 팝업스토어, 콜라보 카페 등 운영 기간(시작일~종료일)이 지정된 성지.
  * 이벤트 기간 종료 시 즉시 **`archived`** 처리되어 신규 영수증 인증 차단.
* **상설형 성지 (상시적)**:
  * 스타 단골 맛집, 앨범 자켓/뮤직비디오 촬영지 등 상시 방문 가능한 거점.
  * **최근 14일 롤링 감쇠**가 적용되어 꾸준한 방문이 없으면 점유율이 감소.

### 2.2 성지 인정 커트라인
1. **결제 영수증 발행 사업장**: 사업자등록번호가 부여되어 오프라인 결제 영수증이 나오는 매장만 성지 등록 가능 (무료 벽화/공원은 MVP 제외).
2. **팬덤 맥락 존재**: 해당 IP 관련 이벤트가 열리거나 사연이 존재하는 지점.

## 3. 화면별 상세 기능 정의

### 3.1 [화면 1] 성지 지도 (Home Map View)
* **지도 뷰포트 (Map Area)**:
  * **구(區) 단위 폴리곤 컬러링**: 구 전체가 현재 점령 중인 1위 팬덤의 대표 고유 색상으로 채색 표현 (40% 미만 미달 시 무주공산 중립 표현).
  * **성지 핀 (Marker)**:
    * **이벤트형 핀**: `D-Day 뱃지` (예: D-2, 오늘마감) 및 팬덤 대표 색상 링 표시.
    * **상설형 핀**: 고정 핀 아이콘 형태로 구분 표시.
* **필터링 & 검색 (Filter Bar)**:
  * `[내 선호 IP만 보기]` 토글 스위치 ➔ 내가 응원하는 팬덤 관련 성지 핀만 지도에 즉시 필터링.
  * `[구(區) 선택 드롭다운]`: 특정 구로 지도 카메라 즉시 이동.
* **바텀 시트 (Bottom Sheet)**:
  * 지도 하단 스와이프 업 바텀 시트 ➔ 현재 지도 화면 뷰포트 내 `[주변 인기 성지 리스트]` 노출 (이벤트 임박순/점유율 치열순 정렬).

### 3.2 [화면 2] 성지 상세 모달 (Spot Detail Modal)
* **성지 정보 헤더**: 장소 상호명, 성지 이벤트명, 운영 기간(D-Day), 주소, 대표 이미지.
* **실시간 팬덤 점유 현황 바 (Progress Bar)**:
  * 이 성지 안에서 발생한 팬덤별 인증 비중 시각화 (예: A 팬덤 55% vs B 팬덤 45%).
* **인증 CTA 버튼**:
  * **`[영수증으로 인증하고 땅 점령하기]`** 버튼 (클릭 시 카메라/OCR 인증 뷰어 오픈).
  * *이벤트 종료(`archived`) 성지일 경우*: `[종료된 성지입니다]` 비활성화 버튼으로 전환.

## 4. 성지 지도 UI 예외 상태 & 인터랙션 명세

### 4.1 핀 클러스터링 정책 (Pin Clustering)
* **발생 조건**: 특정 홍대/성수 구역처럼 동일 건물 또는 50m 이내 반경에 여러 성지 핀이 밀집한 경우.
* **표시 방식**: 핀이 개별적으로 겹치지 않고 숫자가 포함된 `[클러스터 핀 (예: 5)]` 아이콘으로 자동 그룹화.
* **클릭 인터랙션**: 클러스터 핀 클릭 시 해당 지점으로 지도 뷰포트 자동 줌인(Zoom-in) 및 개별 핀 분리 노출.

### 4.2 UI 예외 상태 처리 (Empty / Loading / Error)
* **Loading State (로딩 중)**: 지도 뷰포트 변경 시 성지 핀 위치에 연한 스켈레톤 마커 노출.
* **Empty State (성지 없음)**: 검색 필터 조건(선호 IP만 보기 등) 적용 시 주변에 성지가 없을 경우 바텀시트에 *"이 구역에는 아직 등록된 성지가 없습니다"* 안내 카드 및 `[성지 제보하기]` CTA 노출.
* **Network Error State (네트워크 장애)**: 지도 상단에 *"네트워크 연결이 불안정합니다. 다시 시도해 주세요"* 토스트 메시지 및 `[새로고침]` 버튼 노출.
