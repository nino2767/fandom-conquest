## 1. 개요 및 목적

본 문서는 유저 닉네임 설정뿐만 아니라 추후 서비스 확장에 따른 **댓글, 커뮤니티, 1:1 문의 등 서비스 전역에서 재사용할 수 있는 백엔드 통합 공통 금칙어 필터링 엔진 및 관리 화면(`ADM-SYSTEM-01`)**을 정밀 명세한다.

---

## 2. [ADM-SYSTEM-01] 공통 금칙어 관리 화면 명세

### 2.1 주요 기능 및 데이터 명세
- **금칙어 등록/수정/삭제/일괄 CSV 업로드**:
  - `금칙어 키워드`: 텍스트 (예: 비속어, 사칭어, 혐오 표현)
  - `적용 타깃 (Scope)`: `전체(ALL)`, `닉네임 전용(NICKNAME)`, `댓글/커뮤니티 전용(COMMUNITY)`
  - `차단 방식`: `하드 차단 (입력 거부)`, `마스킹 처리 (*** 변경)`
  - `카테고리`: 비속어, 음란, 사칭, 정치/사회, 타 아티스트 비하
  - `활성화 여부`: `Y / N`
  - `등록자 / 등록일시`: 담당 어드민 ID 및 일시

### 2.2 공통 백엔드 금칙어 차단 정규식 엔진 (Regex Rule)
- 유저가 입력하는 모든 텍스트 필드에 대해 백엔드 입력 유효성 검증 시 금칙어 테이블 정규식 스캔 수행.
- 사칭어 기본 내장 필터 예시: `admin`, `administrator`, `운영자`, `관리자`, `팬덤땅따먹기` 등 포함 시 하드 차단.
