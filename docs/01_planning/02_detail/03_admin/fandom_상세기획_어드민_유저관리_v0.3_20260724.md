## 1. 개요 및 회원 데이터 스키마 명세

본 문서는 서비스 내 전체 회원 정보 조회, 검색, PII 개인정보보호 마스킹 룰, 유저 상세 팝업(Drawer), 프로필 강제 초기화 룰 및 디폴트 프로필 캐릭터 자산 관리(`ADM-USER-02`)를 정밀 명세한다.

### 1.1 회원(User) 프로필 데이터 스키마

| 필드명 | 데이터 타입 | 필수 여부 | 수집/생성 경로 | 설명 및 마스킹 룰 |
| :--- | :--- | :---: | :--- | :--- |
| `user_id` | String (UUID) | **필수** | 시스템 자동 생성 | 유저 고유 식별자 (마스킹 없음) |
| `email` | String | **필수** | 소셜 연동 (Kakao/Google/Apple) | 계정 이메일 주소 (`fan****@kakao.com` 마스킹) |
| `name` | String | **필수** | 소셜 연동 | 실명 (`홍*동 / 김*덤` 마스킹) |
| `phone_number` | String | **필수** | 소셜 CI/DI 인증 연동 | 휴대폰 번호 (`010-****-5678` 마스킹) |
| `birth_date` | Date | *선택* | 소셜 연동 / 유저 입력 | 생년월일 (목록 미노출, 상세에서 마스킹) |
| `provider` | Enum | **필수** | 소셜 가입 세팅 | `KAKAO`, `GOOGLE`, `APPLE` |
| `profile_image_url` | String (URL) | **필수** | 디폴트 캐릭터 → 유저 변경 | 프로필 이미지 URL (디폴트: 서비스 캐릭터) |
| `nickname` | String | **필수** | 온보딩 시 유저 직접 입력 | 앱 내 표시 닉네임 (중복 불가) |
| `primary_fandom_id` | String | **필수** | 온보딩 시 유저 선택 | 메인 선택 팬덤 ID |
| `status` | Enum | **필수** | 시스템 관리 | `ACTIVE`(정상), `WARNING`(경고), `SUSPENDED`(임시정지), `BANNED`(영구정지) |
| `created_at` | DateTime | **필수** | 가입 시 자동 생성 | 회원가입 일시 |
| `last_login_at` | DateTime | **필수** | 서비스 접속 시 자동 갱신 | **마지막 서비스 접속 일시** |

## 2. 화면별 세부 기능 명세

### 2.1 [ADM-USER-01] 유저 목록 & 회원 상세

#### 1) 검색 및 필터 조건 (선택형 vs 키워드 구분)
- **선택 필터 (Select/Dropdown)**:
  - `계정 상태`: 전체(Default), 정상(`ACTIVE`), 1차경고(`WARNING`), 임시정지(`SUSPENDED`), 영구정지(`BANNED`)
  - `가입 소셜`: 전체(Default), 카카오(`KAKAO`), 구글(`GOOGLE`), 애플(`APPLE`)
  - `가입 팬덤`: 전체(Default), 등록 팬덤 목록
  - `가입 기간`: 최근 30일(Default), 전체, 지정 범위 (Date Range)
- **키워드 검색 (Text Input)**:
  - `검색 조건 선택`: 닉네임(Default), 이름, 이메일, 전화번호, 유저 ID
  - `검색어 입력`: 부분 일치 키워드 검색 (`LIKE %kw%`)

#### 2) 유저 목록 테이블 필드 (Table Columns)
1. **프로필**: 썸네일 이미지 + 닉네임 (클릭 시 상세 팝업 열림)
2. **유저 ID**: `usr_98a7f1...` (클립보드 복사 아이콘 제공)
3. **이름 / 이메일**: `김*덤 (fan****@kakao.com)` (마스킹 적용)
4. **전화번호**: `010-****-5678` (마스킹 적용)
5. **가입 소셜**: `[Kakao]` 배지 및 소셜 아이콘
6. **메인 팬덤**: 대표 선택 팬덤명
7. **계정 상태**: `[정상]`, `[경고]`, `[임시정지]`, `[영구정지]` 컬러 배지
8. **누적 인증 / 기여분**: 42건 / 42점
9. **가입일**: `2026-07-20 14:32`
10. **마지막 접속일**: `2026-07-24 19:10`
11. **관리 액션**: `[상세보기]` 버튼

> 🔒 **개인정보 마스킹 해제 권한 및 감사로그**:
> - 목록/상세 상단의 `[개인정보 마스킹 해제]` 버튼 클릭 시 사유 입력 모달 팝업.
> - 사유 입력 후 확인 시 마스킹 해제된 원본 데이터 노출 및 **어드민 감사로그(Audit Log) 자동 기록**.

#### 3) 유저 상세 팝업 (User Detail Drawer)
- **조회 전용 (Read-Only)**: `user_id`, `email`, `name`, `phone_number`, `birth_date`, `provider`, `created_at`, `last_login_at`, 누적 인증/기여 점수
- **어드민 수정 가능 (Editable)**:
  - **`nickname`**: 부적절한 닉네임 시 어드민이 강제 수정 가능
  - **`profile_image_url`**: **`[프로필 강제 초기화]`** 버튼 제공
  - **`primary_fandom_id`**: CS 대응 시 예외 변경
  - **`status`**: 계정 상태 변경 모달 호출
  - **`admin_memo`**: 어드민 내부 전용 운영 메모 (최대 1,000자)

#### 4) 프로필 강제 초기화 룰
- 어드민이 부적절한 프로필에 대해 `[프로필 강제 초기화]` 실행 시:
  - **프로필 이미지**: `ADM-USER-02`에 등록된 활성 디폴트 캐릭터 중 **[랜덤(Random) 지정]**
  - **닉네임**: **[형용사 + 덕후/팬덤 명사 + 3자리 난수]** (예: `행복한덕후104`, `빛나는팬덤582`) 친근한 임의의 닉네임으로 자동 부여

### 2.2 [ADM-USER-02] 프로필 캐릭터/아바타 관리

- **기능 명세**:
