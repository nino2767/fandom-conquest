## 1. [ADM-AUTH-01] 어드민 로그인 & 인증 정책

외부 일반 가입 폼이 없는 닫힌 백오피스 시스템(Closed Admin System)을 적용합니다.

```

```

### 1.1 계정 발급 및 보안 규칙
* **최초 시드 계정**: 초기 배포 시 DB 시드(Seed)로 **최초 슈퍼관리자 계정 1개(`admin@fandomconquest.com`)** 자동 세팅.
* **보안 및 세션 만료**: 60분간 무작업 시 자동 세션 만료 ➔ 로그인 화면 리다이렉트. 5회 연속 비번 실패 시 15분 계정 잠금.

## 2. [ADM-DASH-01] 전황 & 운영 대시보드 (Dashboard)

서비스 주요 KPI 및 25개 구 실시간 점령 전황을 한눈에 파악하는 대시보드 메인 화면입니다.

```
+-------------------------------------------------------------+
|  [ 📊 운영 & 전황 대시보드 ]                  [ 🔄 실시간 갱신]|
+-------------------------------------------------------------+
|  📈 [ 오늘의 주요 운영 지표 (KPI) ]                          |
|  • 일간 승인 인증(DAU): 1,250건  |  자동 승인율: 92.4%     |
|  • 대기 중 수동검수: 12건        |  어뷰징 차단 계정: 3건   |
+-------------------------------------------------------------+
|  🗺️ [ 서울 25개 구 점령 실시간 분포 ]                        |
|  • 💙 뉴진스: 10개 구  |  🔴 아이브: 8개 구  |  🟣 세븐틴: 5개 구  |
+-------------------------------------------------------------+
|  ⚡ [ Real-Time 뒤집힘 타임라인 로그 ]                       |
|  • 14:20 [마포구] 뉴진스가 1위 역전! (최후 역전: 유저 '덕질마스터') |
|  • 12:05 [성동구] 아이브가 1위 역전! (최후 역전: 유저 '럭키팬')    |
+-------------------------------------------------------------+
```

### 2.1 대시보드 모니터링 주요 항목
* **실시간 뒤집힘 현황**: 오늘 발생한 구(區) 단위 역전 이벤트 타임라인 로그.
* **인증 처리 속도 지표**: AI OCR 자동 승인 비율 vs 수동 검수 큐 적재 건수 실시간 미터기.
* **성지 인증 분포 Top 5**: 가장 인증이 활발한 오프라인 핫스팟 매장 순위.
