# 팬덤 땅따먹기 상세기획 — 어드민 반려 사유 프리셋 관리 (v0.2)

> **문서 버전**: v0.2  
> **최종 수정일**: 2026-07-27  
> **문서 상태**: Approved Spec (승인 완료)  
> **관련 화면 ID**: `ADM-PRESETS-01` (반려 사유 프리셋 관리)  
> **관련 영역**: 영수증 인증 반려 처리, AI OCR 자동 검사 엔진 연동, B2C 영수증 인증 반려 알림  

---

## 1. 개요 및 목적

본 문서는 영수증 수동/자동 검수 시 사용자가 영수증을 잘못 올렸거나 조작이 의심될 때 발송하는 **'반려 사유 프리셋'을 어드민 콘솔(`ADM-PRESETS-01`)에서 실시간으로 등록/수정/삭제하고 관리할 수 있도록 명세**한다.

---

## 2. 어드민 기획 Rationale (기획 의도 및 근거)

반려 사유를 하드코딩하지 않고 어드민에서 독립적으로 프리셋을 관리하는 구체적인 이유는 다음과 같다:

1. **운영 기민성 확보**: 신종 위변조 영수증이나 새로운 어뷰징 패턴 발견 시, 개발자 배포 파이프라인을 거치지 않고 운영 리더가 어드민에서 즉각 새로운 반려 사유 프리셋을 등록 및 가동할 수 있습니다.
2. **유저 노출 안내문 표준화**: 반려 사유는 B2C 앱에서 유저에게 알림으로 직접 노출되므로, CS 대응을 최소화할 수 있도록 기획/운영 관점에서 문구의 톤앤매너와 재제출 유도 가이드를 실시간 편집할 필요가 있습니다.
3. **AI OCR 자동 매핑 연동**: 자동 판정 엔진의 오류 코드와 사람이 판단하는 반려 코드를 1:1로 표준 매핑하여, 통계 데이터베이스 구축 시 사유별 반려 통계를 차트화할 수 있도록 지원합니다.

---

## 3. [ADM-PRESETS-01] 반려 사유 프리셋 관리 화면 명세

### 3.1 주요 기능 및 데이터 명세
* **반려 사유 등록/수정/삭제**:
  - `반려 코드 (Reject Code)`: 영수증 반려 코드로 고유값 (예: `REJ-01` ~ `REJ-99`)
  - `노출 사유명`: 수동 검수 시 어드민 콤보박스에 보일 짧은 핵심 제목 (예: "GPS 위치 정보 불일치")
  - `B2C 유저 안내 설명`: 사용자 푸시 알림 및 인증 이력 상세 화면에 표시될 구체적인 재안내 메시지 (예: *"영수증 결제처의 위치와 현재 위치 정보가 200m 이상 어긋납니다. 현장 내에서 다시 신청해주세요."*)
  - `자동 판정 매핑 여부`: AI OCR 자동 검사 규칙과의 맵핑 적용 여부 (`Y / N`)
  - `최종 수정자 / 수정일시`: 어드민 ID 및 최종 타임스탬프

---

## 4. B2C 앱 연동 규격

* 영수증 반려 데이터 저장 시 `reject_code` 외래키를 저장하여, 유저 뷰(`user-view`)에서 반려 내역 조회 시 실시간 활성화되어 있는 프리셋 테이블의 `B2C 유저 안내 설명`을 동적으로 호출해 렌더링합니다.
