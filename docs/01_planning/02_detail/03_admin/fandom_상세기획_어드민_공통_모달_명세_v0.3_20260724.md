## 1. 개요 및 비즈니스 목적

## 3. 공통 모달별 정밀 UI/UX 명세

### 3.1 🔍 [MODAL-COMM-01] 제재 부여 & 기여분 몰수 모달
- **호출 화면**: `ADM-USER-01` (유저 목록), `ADM-ABUSE-01` (이상 탐지), `ADM-SANCTION-01` (제재 관리)
- **UI/UX 명세**:
  1. **제재 대상 요약**: 대상 유저 닉네임, 유저 ID, 현재 계정 상태
  2. **제재 수위 라디오 버튼**:
     - `[ ] 1차 경고 (WARNING)` (경고 푸시 및 이메일 발송)
     - `[x] 2차 임시정지 (SUSPENDED)` (기간 선택 Dropdown: `7일`, `14일`, `30일`)
     - `[ ] 3차 영구정지 (BANNED)` (계정 영구 차단 - 슈퍼관리자 승인 필요)
  3. **제재 사유 카테고리 Select**: `영수증 위조/도용`, `GPS 위치 조작`, `명의/계정 다중 사용`, `기타 어뷰징`
  4. **기여분 몰수 처리 Toggle**: `[x] 어뷰징 건 기여분 회수 및 해당 성지 랭킹 점수 롤백`
  5. **운영자 상세 사유 Textarea**: 어드민 처리 메모 입력 (최대 1,000자)
  6. **Footer Buttons**: `[취소]` / `[제재 부여 확정]` (클릭 시 제재 적용 및 어드민 Audit Log 저장)

---

### 3.2 🔍 [MODAL-COMM-02] 수동 검수 보류 확정 모달
- **호출 화면**: `ADM-ABUSE-01` (이상 탐지), `ADM-VERIF-01` (인증 검수)
- **UI/UX 명세**:
  1. **보류 대상 요약**: "선택된 IP/그룹의 **N개 계정**, **M건의 영수증 인증 건**을 수동 검수 큐로 이관합니다."
  2. **보류 사유 선택 Select**: `동일 IP 다계정 결제 징후`, `GPS 위치 오차 과다`, `영수증 승인번호 패턴 유사`
  3. **점수 유예 체크박스**: `[x] 검수 완료 전까지 해당 건들의 점유율/랭킹 점수 반영 일시 유예`
  4. **운영자 처리 메모 Textarea**: 운영 메모 입력 (최대 500자)
  5. **Footer Buttons**: `[취소]` / `[보류 이관 확정]` (클릭 시 `ADM-SANCTION-02` 수동 검수 큐로 데이터 전송)

---

### 3.3 🔍 [MODAL-COMM-03] 개인정보 PII 마스킹 해제 사유 모달
- **호출 화면**: 어드민 전역 (목록/상세 등에서 PII 마스킹 해제 버튼 클릭 시)
- **UI/UX 명세**:
  1. **주의 안내**: "개인정보(이름, 이메일, 전화번호, 생년월일) 마스킹을 해제합니다. 조치 사유는 감사로그에 저장됩니다."
  2. **열람 사유 선택 Select**: `유저 CS 1:1 응대`, `어뷰징 및 도용 여부 심사`, `소명 서류 검수`
  3. **상세 열람 목적 Textarea**: 열람 목적 입력 (최대 200자)
  4. **Footer Buttons**: `[취소]` / `[마스킹 해제 확인]` (클릭 시 마스킹 해제 원본 표기 및 어드민 Audit Log 자동 저장)

---

### 3.4 🔍 [MODAL-COMM-04] 프로필 강제 초기화 모달
- **호출 화면**: `ADM-USER-01` (유저 목록), `ADM-ABUSE-01` (이상 탐지)
- **UI/UX 명세**:
  1. **초기화 대상 요약**: 유저 닉네임 (`부적절닉네임123`), 현재 프로필 이미지
  2. **초기화 범위 선택 Checkbox**:
     - `[x] 닉네임 초기화` (친근한 렌덤 닉네임 `행복한덕후104` 조합으로 즉시 자동 교체)
     - `[x] 프로필 이미지 초기화` (활성 서비스 디폴트 캐릭터 중 랜덤 지정 교체)
  3. **유저 알림 안내**: "프로필이 초기화되었음을 해당 유저에게 인앱 알림으로 안내합니다."
  4. **Footer Buttons**: `[취소]` / `[프로필 초기화 확정]`
