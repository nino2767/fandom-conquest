# 팬덤 땅따먹기 상세기획 — 백오피스 어드민 (Admin Back-Office Specification)

> 본 문서는 '팬덤 땅따먹기' 백오피스 어드민(Admin Portal)의 **정보 구조(Admin IA), 권한 관리, 거점/성지 관리(Spot Master), 영수증 인증 검수 워크플로우 및 어뷰징 모니터링 명세**를 다룬다.

---

## 1. 어드민 정보 구조 (Admin IA & Permission)

### 1.1 메뉴 계층 구조 (Menu Structure)
```
Admin Portal
├── 1.0 Dashboard (전황 & 운영 대시보드) [ADM-DASH-01]
├── 2.0 Spot Master (거점 & 성지 관리)
│   ├── 2.1 Place Management (장소 가맹점 관리) [ADM-SPOT-01]
│   └── 2.2 Spot Management (성지 핀 이벤트 관리) [ADM-SPOT-02]
├── 3.0 Verification OMS (영수증 인증 검수 관리)
│   ├── 3.1 Verification Data Table (전체 내역) [ADM-VERIF-01]
│   ├── 3.2 Manual Review Queue (수동 검수 큐) [ADM-VERIF-02]
│   └── 3.3 Rejection Preset Management (반려 사유 관리) [ADM-VERIF-03]
├── 4.0 Anti-Abuse & Users (어뷰징 탐지 & 유저 관리)
│   ├── 4.1 Anomaly Monitoring (이상 탐지 모니터링) [ADM-ABUSE-01]
│   └── 4.2 User Management (유저 및 제재 관리) [ADM-USER-01]
└── 5.0 System Settings (시스템 & IP 관리)
    ├── 5.1 Fandom IP Management (팬덤 팀 & 컬러 관리) [ADM-SYS-01]
    └── 5.2 Admin User Permission (어드민 계정 권한) [ADM-SYS-02]
```

### 1.2 어드민 권한 관리 (Role-based Permission)
* **슈퍼 어드민 (Super Admin)**: 전체 메뉴 접근, 팬덤 IP/컬러 관리, 수동 검수 및 상태 변경, 이상계정 제재 처리 권한.
* **운영 검수자 (Operator)**: `3.0 Verification OMS (수동 검수 큐)` 및 `2.0 Spot Master` 읽기/쓰기 권한 전용.
* **파트너 매장 어드민 (Partner Admin - 추후 확장)**: 본인 매장에 등록된 성지 현황 및 인증 통계 조회 전용.

## 2. 거점 & 성지 관리 (Spot Master Specification)

### 2.1 [ADM-SPOT-01] 장소 가맹점 관리 (Place Master)
* **목적**: 영수증 인증의 기준이 되는 물리적 사업자 등록 매장 관리.
* **입력 & 관리 필드**:
  * `사업자등록번호 (10자리)`: **필수 / Unique 검수** (인증 OCR 대조 키)
  * `상호명`, `도로명 주소`, `위도/경도 좌표` (주소 입력 시 자동 지오코딩 API 연동)
  * `소속 구(Region)`: 좌표에 따른 행정구 자동 매핑 (예: `서울 마포구`)
  * `운영 상태`: `OPEN (정상)` / `CLOSED (폐업/양도)`

### 2.2 [ADM-SPOT-02] 성지 핀 이벤트 관리 (Spot Master)
* **목적**: 지도상에 마커 핀으로 표시될 이벤트 거점 생성 및 아카이빙 관리.
* **입력 & 관리 필드**:
  * `연동 장소(Place)`: 사업자등록번호로 기존 장소 선택 매핑
  * `귀속 팬덤(Fandom)`: 성지의 대상 IP 선택 (예: `NewJeans`)
  * `성지 타이틀`: 지도 및 모달에 표시될 이벤트명 (예: `하니 21번째 생일카페`)
  * `성지 유형`: `EVENT (한시적 이벤트)` / `PERMANENT (상설 거점)`
  * `운영 기간`: 시작일 ~ 종료일 (`EVENT` 전용, 종료일 자정 후 자동 `ARCHIVED` 스케줄링)
  * `상태`: `ACTIVE (진행 중)` / `ARCHIVED (종료됨)`

## 3. 영수증 인증 관리 (Verification OMS Workflow)

인증 데이터를 주문관리시스템(OMS) 워크플로우 형태로 통합 검수하는 화면입니다.

### 3.1 [ADM-VERIF-01] 인증 내역 테이블 탭 구조
* **`[전체 내역]`**: 시스템에 접수된 전체 영수증 인증 로그
* **`[자동 승인 탭]`**: AI OCR 인식률 95% 이상으로 자동 처리 완료된 건 (운영 리소스 0%)
* **`[수동 검수 큐 탭]`**: ⚠️ **운영자 집중 검수 탭** (GPS 오차, 인식률 저하, 이상징후 건)
* **`[최종 반려 탭]`**: 중복/쿨다운/미일치 사유로 반려된 건

### 3.2 [ADM-VERIF-02] 수동 검수 큐 워크플로우 (Manual Review Workflow)
수동 검수 큐에 인입된 건은 **좌/우 2분할 대조 UI**를 통해 빠른 검수를 수행합니다.

```
+------------------------------------+------------------------------------+
|  [좌측: 제출 영수증 원본 이미지]   |  [우측: AI 판독값 & 검수 판정]    |
|                                    |  • 유저 닉네임: 지수(뉴진스팬)     |
|   +----------------------------+   |  • 성지 장소명: 어반소스           |
|   |  영수증 캡처/촬영 이미지  |   |  • 성지 사업자: 123-45-67890       |
|   |                            |   |  • OCR 읽은값: 123-45-67890 [일치] |
|   |  - 상호명                  |   |  • 결제일시: 2026-07-22 14:20:00   |
|   |  - 사업자번호: 123-45-67890|   |  • 결제금액: 15,000 KRW            |
|   |  - 승인번호: 87654321      |   |  • 승인번호: 87654321              |
|   +----------------------------+   |  • GPS 위치거리: 45m 이내 [정상]   |
|                                    |                                    |
|                                    |  [승인 확정]    [반려 (사유선택)]  |
+------------------------------------+------------------------------------+
```

* **승인 확정 클릭 시**: `status ➔ APPROVED` 전환, 해당 구 점유율 즉시 확정 반영 및 유저에게 푸시 알림 발송.
* **반려 클릭 시**: 반려 사유 프리셋 모달 오픈 (사유 선택 후 즉시 유저 알림 발송).

## 4. 어뷰징 탐지 및 모니터링 (Anti-Abuse & Analytics)

### 4.1 [ADM-ABUSE-01] 이상 탐지 대시보드 (Anomaly Dashboard)
* **10분간 인증 급증 핫스팟 탐지**: 특정 성지에서 10분 내 30건 이상 인증 몰릴 경우 감지 경고 뱃지 노출.
* **동일 IP 다계정 탐지**: 단일 IP 주소에서 복수의 유저 계정으로 영수증 제출 시 수동 검수 큐 자동 강제 이관.
* **블랙리스트 관리**: 상습 재활용 영수증 업로드 유저 ➔ `SUSPENDED` 상태 전환 및 영수증 인증 기능 차단.

### 4.2 [ADM-DASH-01] 전황 & 운영 대시보드
* **실시간 뒤집힘 현황**: 오늘 뒤집힌 구(區) 리스트 및 최후의 역전 유저 타임라인.
* **핵심 지표 (KPI)**: 일간 승인 인증 건수(DAU), 성지별 인증 분포 Top 5, 구별 1위 팬덤 분포 현황.
