# 팬덤 땅따먹기 상세기획 — 화면 목업 오버뷰 (Screen Mockup Overview)

> 본 문서는 '팬덤 땅따먹기' 주요 앱 화면 4종의 UI 컴포넌트 구조 및 뷰 아키텍처를 정의한다.

---

## 1. 프론트엔드 (App) 화면 아키텍처

### [화면 1] 팬덤 성지 지도 (Home Map View)
- **Map Area**: 폴리곤 형태의 팬덤별 구(區) 단위 점유 구역 컬러링, 개별 장소/성지 핀(마커) 및 D-Day 뱃지.
- **Header Bar**: 선호 IP 토글 필터, 구 단위 이동 드롭다운, 검색 버튼.
- **Floating Bar**: `[내 주변 성지 리스트]` 스와이프 업 바텀 시트.

### [화면 2] 성지 상세 및 인증 모달 (Spot Detail Modal)
- **Header**: 장소명, 이벤트명, 운영 기간(D-Day 뱃지), 주소.
- **Progress Bar**: 현재 성지의 팬덤별 실시간 점유율 현황 (예: A그룹 60% vs B그룹 40%).
- **CTA 버튼**: `[영수증으로 인증하기]` (클릭 시 카메라/OCR 뷰어 오픈).

### [화면 3] AI 인증 결과 화면 (AI Verification Result)
- **Interaction**: "AI가 영수증 및 사업자 번호를 판독 중입니다" 로딩 애니메이션.
- **Feedback**: "인증 완료! 마포구 영토 점유율이 +0.4% 상승했습니다" 결과 팝업.

### [화면 4] 랭킹 보드 (Leaderboard)
- **Tab**: `[누적 개인 랭킹]` / `[팬덤 영토 점유 랭킹]`.
- **Range Filter**: 전체 기준 / 구(區) 단위 세부 기준.
