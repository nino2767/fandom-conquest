> [1. 기획 개요 & 핵심 정책] 3장을 전제로, **팬덤(점령·랭킹의 집계 단위 + 지도 색)의 등록·색·집계 규칙**을 정리.

# 1. 등록 · 관리
- 팬덤은 운영자가 등록(이름=IP, 컬러). 유저가 만들지 않음.
- MVP는 소수 1~2개 팬덤군만. 대상 IP 선별은 성지 밀집도 기준.

# 2. 색(컬러)
- 팬덤마다 고유 컬러 1개. 지도 점령 표시의 기준.
- 색 충돌 방지: 등록 시 기존 팬덤과 구분되는 색 배정(대비 확보). 공식 팬덤 컬러 있으면 우선 사용.

# 3. 집계 단위
- 점령·랭킹은 팬덤(그룹) 단위로만 합산. 멤버(스타)는 성지 이벤트명 메타로만, 독립 집계축 아님(추후 확장).

# 4. 유저 없는 팬덤
- 등록됐지만 아직 인증 0인 팬덤은 지도엔 안 뜸(점유 0 = 색 없음). 첫 인증부터 색 등장.

# (미결)
- 같은 IP의 유닛/서브그룹(그룹 vs 솔로 활동)을 별개 팬덤으로 볼지 → 멤버 세분화와 함께 추후.
- 팬덤 병합/분리(그룹 해체·재편) 시 점수 처리 → 추후.
