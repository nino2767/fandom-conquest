> [1. 기획 개요 & 핵심 정책] 3장을 전제로, **팬(서비스 유저)의 로그인·선호팬덤·귀속·계정 처리 규칙**을 정리.

# 1. 로그인 · 계정
- 이메일/소셜 로그인. 한국 휴대폰 본인인증 비의존(외국인 포용).
- 1인 1계정 원칙. 다계정은 어뷰징(문1 6장 4차 이상탐지) 대상.

# 2. 선호 팬덤 · 귀속
- 선호 팬덤 다중 선택·언제든 변경(지도 필터·인증 기본값).
- 인증은 그 순간 선택한 팬덤 1개에 귀속. 선호 변경은 미래 인증에만 적용.
- **과거 점수 불변**: 선호 팬덤을 바꿔도 이미 한 인증의 귀속·점수는 그대로(소급 없음). 어뷰징 방지 + 이력 일관성.

# 3. 팬 증명 없음
- 팬임을 증명하는 절차 없음. 귀속 팬덤은 자기 신고. 진입 허들 최소화.
- 상대 팬덤으로 신고해 방해(역점령)? 결제·GPS·건수 코스트가 있어 대규모 조작은 비경제적. 이상패턴은 검수 큐.

# 4. 계정 삭제 · 탈퇴
- 삭제 시 개인정보(로그인 정보)는 파기. 단 그 유저의 인증이 만든 땅 점유·팬덤 집계는 익명화된 형태로 유지(팬덤 점수는 개인이 아니라 팬덤 소유). 땅이 갑자기 빠지면 게임 훼손.
- 개인 랭킹에서는 제외.

# (미결)
- 국가/언어별 온보딩 카피, 위치권한 거부 시 UX(인증 GPS 불가) → 기능 명세에서.
- 부정 계정 제재 수위(경고·정지) → 운영정책 추후.
