> [1. 기획 개요 & 핵심 정책] 3장을 전제로, **장소(성지가 얹힐 그릇)의 식별·중복·상태전이 규칙**을 정리.

# 1. 식별 · 유일키
- 유일키 = **사업자번호**(한국 10자리). 상호·주소는 참고 메타.
- 운영자 등록 시 사업자번호 중복이면 신규 생성을 막고 기존 장소로 연결.

# 2. 한 주소에 사업자번호 여러 (푸드코트·복합몰)
- 사업자번호 기준이라 각각 **별개 장소** → 지도엔 근접 핀 여러. 좌표가 같아도 사업자번호로 구분.

# 3. 사업자번호를 모르는 자연발생 성지 (단골집·촬영지)
- 운영자가 사업자번호 조회해 등록. 못 찾으면 보류(등록 안 함). MVP는 결제형만이라 사업자번호 필수.

# 4. 상태 전이
- **운영 → 폐업**: status=closed. 삭제 금지(과거 인증·랭킹 보존).
- **사업자번호 변경**(양도·업종전환): 기존 장소 closed + 새 사업자번호로 새 장소 생성. 두 장소는 이력상 별개.
- **상호만 변경**: 같은 장소, 상호 필드만 업데이트.

# 5. 좌표 · 구 매핑
- 등록 시 주소 지오코딩으로 좌표·소속 구(region) 확정. 구가 성지 집계 단위(2레벨).

# (미결)
- 임시 사업자·위탁결제 팝업 등 사업자번호가 애매한 케이스 → 나오면 검토.
- 이전 후 같은 자리의 새 사업자가 이전 팬덤 성지를 이어받는지(이력 승계) → 추후.
