> [1. 기획 개요 & 핵심 정책] 3장을 전제로, **인증(영수증 행위)의 플로우·판정·예외 규칙**을 정리. 점수의 최소 단위이자 어뷰징 방어의 최전선(4겹 방어 상세는 문1 5장).

# 1. 플로우
카메라 → OCR 판독 → dedup 체크 → GPS·인식률 판정 → (자동승인 / 수동검수 큐) → 결과 피드백.

# 2. OCR 추출 필드
사업자번호, 거래일시, 금액, 승인번호. 원본 이미지는 검수 후 파기·마스킹(개인정보).

# 3. 판정 규칙
- dedup_key(승인번호 없으면 거래일시+사업자번호+금액) 중복 → 즉시 반려.
- 사업자번호가 성지 장소와 일치 + 인식률 높음 + GPS 반경내 → 자동 승인(즉시 확정).
- GPS 밖 / 인식률 낮음 / 이상신호 → 수동검수 큐.
- 쿨다운 초과 → 반려. 귀속 팬덤은 인증 시점 선택 1개.

# 4. 쿨다운 · 재시도
- 쿨다운: 성지당 1일 1회, 자정(KST) 리셋(땅 상세정책과 동일).
- 반려된 인증은 '시도'로 치지 않음 → 정당한 재촬영은 같은 날 재인증 허용, 단 같은 영수증(dedup)은 여전히 차단.
- 수동검수 대기 건은 잠정 점유 미반영, 승인 후 반영.

# 5. 예외 케이스
- 한 매장에서 이벤트 동시 복수: 영수증은 사업자번호 1개 → 그 장소의 '현재 활성 성지' 1개에 귀속. MVP는 1장소 1활성성지로 단순화.
- OCR이 사업자번호 못 읽음: 조합키로 dedup만, 자동대조 실패 → 수동검수.
- 상설 성지 반복 방문: 쿨다운 + 14일 롤링 감쇠로 자연 조절.

# (미결)
- 자동승인 인식률 임계 수치(예: 95%) → 파일럿 데이터로 튜닝.
- 반려 사유 코드·안내 문구 → 기능 명세에서.
