# 흐름
S0 온보딩 → S1 지도(홈) → S2 성지 상세 → S3 인증 → S4 전황 → S5 랭킹

# S0. 온보딩 (선호 IP)
- **목적**: 진입 허들 최소화 + 지도 필터 세팅.
- **구성**: 선호 팬덤 다중 선택, 이메일/소셜 로그인(휴대폰 인증 없음).
- **데이터**: users, user_fandoms.

# S1. 성지 지도 (홈) — 핵심
- **목적**: "내 팬덤 색으로 물든 땅"의 첫인상. 땅따먹기 감각의 출발.
- **구성**: 성지 핀(진행중 D-day/상설) + 구 단위 색칠 + 선호 IP 필터.
- **데이터**: spots, places, regions + 즉석 점유 계산.

# S2. 성지 상세
- **목적**: 이 성지에서 뭐를 하면 되는지 + 현재 점유 경쟁.
- **구성**: 장소·이벤트명·D-day, 팬덤별 점유율 바, [영수증 인증] CTA.
- **데이터**: spots, verifications 집계.

# S3. 영수증 인증 (핵심)
- **목적**: 핵심 액션의 쾌감. "찍고 → 판독 → +0.4%, 뒤집힘".
- **구성**: 카메라 → "AI 판독 중" → 결과("마포 +0.4%" / 반려 사유).
- **데이터**: verifications(자동승인/수동검수), 잠정 반영.

# S4. 점령 전황
- **목적**: 뺏고 뺏김의 재미. "게임"이 보이는 화면.
- **구성**: 구별 점령 현황(1위·2위 격차), 뒤집힘 알림, "위태로움" 방어 유도.
- **데이터**: region 즉석 점유, 40% 판정.

# S5. 랭킹
- **목적**: 경쟁·소속감.
- **구성**: 개인 랭킹(누적) / 팬덤 랭킹(현재 점유), 전체·구 범위.
- **데이터**: verifications 카운트 / region 점유.
