# 1. 치명적 리스크 (실행 전 필수)
- **IP·상표 사용**: 팬덤 컬러·아이돌명·로고 노출은 엔터사 권리와 부딪힐 수 있다. 안전한 출발선은 **팬이 직접 입력·큐레이션하는 UGC 구조**(공식 제휴 아닌 "팬들이 모은 정보"). 로고·공식 이미지 직접 사용은 피하고, 규모가 커지면 제휴로 정식화.
- **개인정보 2종**:
	- 영수증 이미지엔 카드번호 일부 등이 담김 → OCR로 **필요 필드(사업자번호·일시·금액·승인번호)만 추출**, 원본은 검수 후 파기 또는 마스킹.
	- 위치정보 수집은 **명시적 동의** 필수(위치기반서비스 법적 고지·동의 의무).
	- 둘 다 개발 초기에 데이터 설계로 박아둘 것.

# 2. 국제화 & 글로벌 확장
방향: **한국 시장 우선 + 외국인 사용자 포용**. 다국가(multi-country)가 아니라 다국어·다통화 대응이 핵심 — 성지는 한국 땅이지만 쓰는 사람이 외국인일 수 있다.
- **지금 하는 것**: UI 다국어(최소 한/영, 텍스트 리소스 분리), 유저 `locale`·`preferred_language` 필드, 외국인 가능한 로그인(이메일/소셜).
- **인증 코어는 그대로**: 외국인도 한국 가맹점 결제면 한국 영수증 → 사업자번호·KRW 로직 그대로 동작.
- **지금 안 하는 것**(진짜 해외 진출 시): country_code+business_id 다국가 장소 체계, 통화 다양화, 국가별 OCR 파서, 지역별 개인정보 법규 대응.
