## 1. 장소(Place) vs 성지(Spot) 도메인 아키텍처

### 1.1 도메인 개념 및 유일키 정의
* **장소 (Place)**: 10자리 사업자등록번호(`biz_no`)로 식별되는 현실의 물리적 사업장 매장.
  * **정책**: 상호나 도로명 주소가 바뀌어도 사업자등록번호가 같으면 **동일 장소**로 취급하여 과거 점유 이력을 연결.
* **성지 (Spot)**: 한 장소 위에 얹히는 팬덤 맥락 및 결제 영수증 이벤트 (1개 장소에 여러 성지가 시차를 두고 생성 가능).

### 1.2 공통 상세 모달 아키텍처 (`UV-MAIN-02`)
장소 상세와 성지 상세는 **동일한 공통 상세 모달/바텀시트 레이아웃(`UV-MAIN-02`)을 공유**하되, 성지 상태 및 탭 전환으로 정보를 제공한다.

```
       +-------------------------------------------------------+
       |             [공통 상세 모달 (UV-MAIN-02)]             |
       |  • 상단: 매장 전경 / 포스터 히어로 갤러리 슬라이더    |
       |  • 헤더: 장소 상호명 + 이벤트명 (예: 어반소스 × 하니) |
       +-------------------------------------------------------+
                                   |
                  +----------------+----------------+
                  |                                 |
         [탭 1: 현재 성지 점유율]          [탭 2: 장소 히스토리]
         • 팬덤별 점유 프로그레스바        • 이 장소(사업자번호)에서
         • 기여 유저 Top 3 포디움          과거에 열렸던
         • 최근 인증 타임라인              이전 성지 이력 목록
```

## 2. 장소 & 성지 데이터 생애주기 (Lifecycle) 및 상태 정책

### 2.1 생성 및 등록 방식 (어드민 큐레이션 + 유저 제보)
* **어드민 직접 큐레이션 (초기 MVP)**: 운영자가 주요 생일카페/팝업스토어 정보를 어드민(`ADM-SPOT-01`)에서 선제적 등록.
* **유저 제보 등록 (`UV-SPOT-04`)**: 유저가 성지 제보 폼을 제출 ➔ 어드민 성지 검수 큐(`ADM-SPOT-03`)로 이관 ➔ 관리자 검토/승인 시 정식 지도 마커 핀 생성.

### 2.2 성지 유형 및 소멸/감쇠 정책
1. **이벤트형 성지 (`EVENT`)**:
   * 생일카페/팝업스토어 등 운영기간 지정 성지.
   * **아카이빙**: 운영 종료일 자정 후 자동으로 `status = ARCHIVED` 전환 (추가 인증 차단, 탭 2 장소 히스토리로 이동).
2. **상설형 성지 (`PERMANENT`)**:
   * 단골집/촬영지 등 상시 거점.
   * **14일 롤링 감쇠**: 최근 14일 이내 인증 건수만 점유율 점수에 반영하여 지속적인 방문 유도.

### 2.3 폐업(CLOSED) 매장 및 신규(NEW) 매장 처리 규칙
* **폐업 매장 (`status = CLOSED`)**:
  * 매장 폐업 확인 시 삭제하지 않고 `CLOSED` 상태 변경.
  * 지도 핀에 🔒 **`[폐업/종료된 매장]`** 아카이브 뱃지 노출.
  * **영수증 인증 불가 차단**: 폐업 매장에서 인증 시도 시 ❌ *"폐업 처리된 매장은 영수증을 인증할 수 없습니다"* 하드 차단 (단, 과거 지분율과 기여 이력은 영구 보존).
* **신규 매장 (`status = ACTIVE` & 등록 7일 이내)**:
  * 지도 핀 상단에 🆕 **`[신규 등록 거점]`** 라이징 뱃지 노출 ➔ 초기 방문 인증 독려.

## 3. 위치 서비스(LBS) 승인 & GPS 반경 판정 정책

### 3.1 위치 권한 승인 절차 (Permission Flow)
1. **[Step 1] 온보딩 LBS 약관 동의 (필수)**: 가입 시 위치기반서비스 이용약관 동의.
2. **[Step 2] OS GPS 권한 승인 팝업**: 메인 지도 진입 직후 1회 브라우저/OS 표준 위치 허용 팝업 호출.

### 3.2 LBS GPS 반경 판정 & 예외 검수 이관
* **인증 가능 반경**: 유저의 실시간 GPS 위치가 성지 중심 좌표 기준 **반경 200m 이내**일 때만 자동 승인.
* **위치 오차 / 권한 미허용 대응**:
  * 위치 반경 200m 밖이거나 위치 권한을 거부한 유저가 영수증 인증 시 ➔ 하드 차단하지 않고 **4차 수동 검수 큐(`ADM-VERIF-04`)로 자동 이관**하여 관리자가 영수증 주소 대조 후 10분 내 처리.
