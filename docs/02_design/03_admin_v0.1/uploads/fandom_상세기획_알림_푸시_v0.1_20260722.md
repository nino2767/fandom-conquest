## 1. 알림 유형 및 트리거 시나리오 명세

| 알림 카테고리 | 알림 타이틀 | 발생 조건 (Trigger) | 푸시(Push) 여부 | 딥링크(Deep Link) 이동 경로 |
| :--- | :--- | :--- | :--- | :--- |
| **영토 뒤집힘<br/>(Territory Flip)** | ⚡ **[구 이름] 점령지가 역전당했어요!** | 유저의 메인 팬덤이 1위이던 구(區)의 점유율이 타 팬덤에 의해 역전당해 1위를 빼앗겼을 때 | **발송 (Push)** | 메인 지도 ➔ 해당 구(區) 뷰포트로 즉시 포커싱 |
| **방어/위협<br/>(Defense Alert)** | 🛡️ **[성지명] 거점이 위태로워요!** | 내 메인 팬덤 점유율 1위 성지의 2위 격차가 5%p 이하로 좁혀졌을 때 | **발송 (Push)** | 해당 성지 상세 모달 (`UV-MAIN-02`) 즉시 팝업 |
| **수호신 위협<br/>(Guardian Alert)** | 👑 **수호신 칭호가 위협받고 있어요!** | 해당 구(區) 개인 기여도 1위 유저('수호신')의 인증 건수를 타 유저가 1건 차이로 바짝 추격 시 | **발송 (Push)** | 랭킹 보드 개인 기여도 상세 (`UV-RANK-02`) |
| **영수증 검수<br/>(OCR Review)** | 🎉 **영수증 인증 승인 (+0.4% 기여)** | 4차 수동검수 큐에 대기 중이던 영수증이 관리자에 의해 최종 승인/반려 판정 시 | **발송 (Push)** | 마이페이지 인증 내역 (`UV-MY-03`) |
| **이벤트/공지<br/>(Event & System)** | 📢 **[신규 성지] 새로운 거점 오픈!** | 내 선호 팬덤의 새로운 이벤트 성지가 내 주요 활동 구에 정식 등록되었을 때 | 선택적 발송 | 해당 성지 상세 모달 (`UV-MAIN-02`) |

## 2. 모바일 푸시(Push) 발송 정책 & 어뷰징 방지

* **푸시 피로도 방지 (Cooldown)**:
  * **영토 뒤집힘 알림 쿨다운**: 동일 구(區)에서 뺏고 뺏김이 잦은 경우 30분 이내 동일 구 뒤집힘 알림 중복 발송 제한 (1개 구당 30분 쿨다운).
  * **방어 위협 알림 쿨다운**: 동일 성지당 1일 최대 1회로 제한.
* **수신 동의 정책 (Opt-in)**:
  * 온보딩 Step 2 마케팅/푸시 수신 동의와 별개로, **게임 플레이 필수 알림(뒤집힘/검수결과)은 서비스 알림**으로 분리 제공.
  * 마이페이지 서비스 설정(`UV-MY-05`)에서 푸시 알림 카테고리별 ON/OFF 개별 토글 가능.

## 3. 알림 센터 UI/UX 화면 명세 (`UV-NOTIF-01`)

### 3.1 진입 경로 및 상단 헤더
* **진입**: 메인 지도 상단 헤더의 **알림 🔔 아이콘** 클릭.
* **미확인 뱃지**: 읽지 않은 알림이 있을 경우 🔔 아이콘 우상단에 Red Dot (🔴) 또는 안 읽은 알림 개수 뱃지 노출.

### 3.2 알림 센터 항목 UI 구성
* **탭 구별**: `[전체 알림]` / `[영토전 알림]` / `[인증/검수]`
* **항목 디자인**:
  * 카테고리 아이콘 (⚡ 뒤집힘, 🛡️ 방어, 🎉 승인, 📢 공지)
  * 알림 메시지 텍스트
  * 상대 시간 표기 ("방금 전", "10분 전", "어제")
  * 안 읽은 항목 배경 색상 구분 (Unread: 연한 팬덤 테두리 / Read: 일반 백그라운드)
* **인터랙션**:
  * 카드 클릭 시 ➔ 해당 알림의 **딥링크Target(성지 상세 or 특정 구 지도 뷰포트)으로 바로 이동**.
  * `[모두 읽음으로 표시]` 및 `[⚙️ 알림 설정]` 버튼 제공.

## 4. 알림 설정 정책 & 세부 기능 명세 (`UV-MY-05` 연동)

### 4.1 디바이스 OS 시스템 알림 권한 연동
* **감지**: OS(iOS/Android) 차원에서 앱 알림이 꺼진 경우 최상단에 ⚠️ *"디바이스 설정에서 알림을 허용해 주세요 [설정으로 이동]"* 안내 뱅크 노출.
* **스위치 잠금**: OS 알림 차단 시 하위 세부 알림 토글 스위치가 비활성화(Disabled) 상태로 락(Lock) 처리.

### 4.2 카테고리별 세부 알림 토글 4종

| 알림 분류 | 세부 토글 항목 | 기본값 | 정책 및 세부 동작 |
| :--- | :--- | :--- | :--- |
| **영토전 게임 알림** | **영토 뒤집힘 알림** | **ON** | 내 메인 팬덤 점령 구(區)가 타 팬덤에 의해 역전당했을 때 푸시 수신 (30분 쿨다운 적용). |
| | **성지 방어 & 수호신 알림** | **ON** | 내 점유율 1위 성지의 2위 격차가 5%p 이하로 좁혀지거나 수호신 칭호 추격 시 푸시 수신. |
| **인증 & 활동 알림** | **영수증 검수 결과 알림** | **ON** | 수동 검수 큐에 등록된 영수증 승인/반려 판정 시 결과 푸시 수신. |
| **혜택 & 마케팅 알림**| **신규 성지 & 이벤트 소식** | **선택동의값** | 내 선호 팬덤의 새 팝업/생카 성지 등록 및 이벤트 소식 (마케팅 수신동의 연동). |

### 4.3 야간 알림 제한 & 방해금지 시간대 (Quiet Hours) 설정
* **야간 알림 제한 (21:00 ~ 08:00)**: 정보통신망법 제50조 준수 및 수면 보호를 위해 야간 시간대 광고성/영토전 알림 기본 무음 처리.
* **사용자 맞춤 방해금지 시간대**:
  * `[방해금지 시간대 설정]` ON/OFF 스위치 제공.
  * **시간 선택 픽커**: 시작 시각(기본 `22:00`) ~ 종료 시각(기본 `07:00`).
  * **동작**: 지정 시간 동안 푸시 팝업/소리/진동을 발생시키지 않고 **알림 센터(`UV-NOTIF-01`)에만 무음으로 조용히 누적**.
* **야간 마케팅 푸시 법적 동의**: 야간 성지 소식 알림 토글을 켤 때 *"야간(21:00~08:00) 광고성 정보 수신에 동의하시겠습니까?"* 동의 팝업 호출 후 동의 일시(`agreed_at`) DB 저장.
