## 2. 세부 비용 산정 및 전략 분석

### 2.1 푸시 서버 & 대기열 인프라
- FCM은 건수 제한 없는 100% 무료 푸시 서비스이므로 API 비용은 $0원.
- 초당 수천 건 실시간 동시 발송을 위한 대기열(Redis Queue / AWS SQS) 인프라 비용 월 약 2만~4.5만원 발생.

### 2.2 카카오 알림톡 / SMS (대체 수단)
- 푸시 수신 거부 유저나 중요 본인인증/제재 통보 시 사용.
- 알림톡 건당 약 6.5원, SMS 건당 9~11원. 초기에는 앱 푸시 중심 발송으로 알림톡비 최소화.
