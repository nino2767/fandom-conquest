# fandom-conquest (우리들의 성지 땅따먹기)

IP 팬덤 기반의 위치 정보(LBS) 게이미피케이션 커머스 서비스인 **'우리들의 성지 땅따먹기 (가칭)'**의 공식 레포지토리입니다.

## 📂 프로젝트 구조

```
fandom-conquest/
  ├── docs/                        # 기획, 설계, 협업 가이드 문서 저장소
  │    └── 01_상위기획-및-방향성/    # 서비스 상위기획 및 노션 동기화 문서
  │
  └── .agents/                     # AI 에이전트 자율 가이드라인 규칙 및 스킬 파일군
       ├── rules/                  # 각 역할군별 코딩 및 오케스트레이션 규칙
       └── skills/                 # 문서 스타일 컴파일 등 에이전트 확장 스킬
```

## 🛠️ 기술 스택 (예정)

*사용자가 목업 프로젝트를 이식한 이후에 확정 및 업데이트 예정입니다.*

## 👥 에이전트 역할군

본 프로젝트는 다음 5가지 자율 에이전트 협업 체계로 개발이 진행됩니다:
1. **PM @한결**: 로드맵, 세션 및 WBS 총괄 관리
2. **기획 @여울**: 제품 기능 및 비즈니스 요건 구체화
3. **디자인 @다올**: 모바일 퍼스트 레이아웃 및 디자인 시스템 준수
4. **개발 @가온**: 기능 개발, ESLint/Lint 빌드 정합성 확보
5. **QA @바른**: 영수증 인증 예외 케이스 처리 검수 및 빌드 무결성 보장
